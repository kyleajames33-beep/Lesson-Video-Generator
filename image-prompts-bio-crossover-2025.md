# Image generation prompts — Biology crossover build (2025 syllabus), Sept 2026

Hook images for the new Year 11 Biology lessons and for Year 12 lessons that were reworked to serve both the 2017 and 2025 syllabus (see docs/biology-syllabus-crossover.md). Same rules as the other Biology prompt files: every image MUST be a **transparent PNG with a real alpha channel** and contain **no text, letters, numbers or labels**. The videos now use a light stage, so avoid very pale edges that disappear against off-white.

Save each file to `public/assets/<path>`. All keys are already registered in `src/assets/index.ts`; until a file exists, the video draws a placeholder in its slot.
