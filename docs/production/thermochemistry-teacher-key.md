# Thermochemistry transfer tasks: separate teacher key

Use with the [student sheet](thermochemistry-learner-tasks.md). Keep this key
out of the student's initial response interval. Each task is worth five
formative points as allocated below; accept equivalent sound explanations
and carried working with a diagnosed arithmetic error. This is a draft local
rubric, not official marking guidance. No learner responses have been collected.

Do not award the inference points for memorised “weak means less heat” or for
calling −57.3 a universal maximum. Equally, do not infer that the synthetic X
data demonstrate a specific real-acid exception or validate an apparatus.
Supplied exercise assumptions make calculations possible; real measurements
must establish whether those assumptions are appropriate.

Record initial answers before feedback, then an amended explanation. Diagnose
reaction-basis errors separately from sign, arithmetic and causal overreach.
For a missed inference, ask what observations the model actually supplies and
what extra evidence would distinguish competing explanations. A correct answer
on this sheet is one formative observation, not achieved course/practical status.

Teacher review should check age/course suitability, whether the reference-state
and Ka distinctions need scaffolding, and whether five-point rubrics capture
the intended reasoning. The Year 12 named practical still needs a supervised,
approved procedure and an actual raw-data record. No laboratory method or
practical-completion evidence is supplied by these synthetic tasks.
