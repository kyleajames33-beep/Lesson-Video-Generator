# Brief 77: extra HSC-style practice questions for every published Module 5 video (site content draft)

Read `00-standing-rules.md` first. For each published Module 5 video (see `youtube/*-uploads.json`), write three new HSC-style questions that practise exactly what that video teaches:
- one short recall or explain question (2 to 3 marks);
- one application in an unfamiliar context (3 to 4 marks);
- one harder question (4 to 5 marks, multi-step or data-based).

**Rules:**
- Each question is worded as an exam would word it. Use the 2017 syllabus verbs.
- Each answer has marking criteria and a sample answer.
- Recompute every number twice. Ksp values must come from the NESA data sheet.
- Don't repeat the video's own practice questions or the site's existing questions (check the site lesson, read-only).
- Use Australian spelling, and no em dashes.

**Output:** `docs/production/claude-pm/practice-bank/m5/<lessonId>.md`, plus an index. Mark everything as a draft for the owner, for the site or the video descriptions. Hand in to `status.md`.
