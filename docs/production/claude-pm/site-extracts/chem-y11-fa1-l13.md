## 3. Key ideas in order

1. Periods and Groups: The periodic table is laid out so that an element's position reveals its electron arrangement: rows track how many energy levels are in use, and columns track the outer electrons that drive chemistry.
2. The s, p, d and f Blocks: The periodic table is divided into blocks, where each block is the part of the table in which the outermost electrons are filling a particular type of sublevel.
3. Effective Charge of an Ion: An ion has a net charge because its number of electrons no longer matches its number of protons.

## 4. Key terms

- Period: A horizontal row of the periodic table; the period number equals the highest principal energy level ($n$) being occupied.
- Group: A vertical column; elements in a group share the same number of valence electrons and similar chemical behaviour.
- Block: A region of the table (s, p, d or f) named for the sublevel that the outermost electrons are filling.
- Atomic number ($Z$): The number of protons in an atom; it equals the number of electrons in a neutral atom.
