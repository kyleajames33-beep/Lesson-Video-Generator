## 3. Key ideas in order

1. What You Can Measure to Track a Rate: You cannot measure "rate" directly, you measure something that changes as the reaction proceeds, and watch how fast it changes with a stopwatch.
2. Controlling the Variables for a Fair Test: A fair test changes only one thing at a time, so any change in rate can be blamed on that one factor and nothing else.
3. Reliability, Validity and Graphing the Results: Good data is both reliable (repeats agree with one another) and valid (it actually measures the effect of the one factor you changed).

## 4. Key terms

- Reaction rate: How fast a reactant is used up or a product is formed, measured as a change in amount divided by the time taken.
- Independent variable: The one factor you deliberately change (for example, the concentration of acid or the temperature).
- Dependent variable: The quantity you measure to judge the rate (for example, gas volume, mass lost, or the time for a mark to vanish).
- Controlled variable: Any factor kept the same in every trial so the test is fair (for example, the total volume, the mass of metal, the apparatus).
