Recombinant DNA Technology and Transgenic Organisms. How do molecular tools join selected DNA and put it to work in a host?

## 2. Syllabus content covered

“describe techniques and applications used in recombinant DNA technology, for example:”

## 3. Key ideas in order

1. A restriction enzyme cuts a selected DNA fragment and a vector at compatible sites.
2. DNA ligase joins the fragment to the vector; the vector carries recombinant DNA into a host cell.
3. The host copies or expresses the inserted gene to make DNA copies, a protein or a transgenic product.
4. PCR can amplify a target sequence and a gel can separate fragments by size as supporting techniques.
5. Directly inserted DNA distinguishes a transgenic organism from one produced only by controlled breeding.

## 4. Key terms

- Recombinant DNA: “DNA formed by combining genetic material from different sources.”
- Restriction enzyme: “An enzyme that cuts DNA at specific base sequences.”
- DNA ligase: “An enzyme that joins DNA fragments together.”
- Vector: “A carrier, such as a plasmid, used to move DNA into a host cell.”
- Host cell: “The cell that receives recombinant DNA and can replicate or express it.”
- Transgenic organism: “An organism containing inserted DNA from another source.”

## 5. Worked examples

- The Humulin example traces a human insulin sequence through a plasmid into *E. coli*, which produces insulin precursors for processing and purification.
- A six-mark description orders isolation, vector preparation, ligation, host transfer and selection. Another six-mark answer explains shared genetic code, a host-recognised promoter, intron-free cDNA and suitable protein processing.

## 6. Misconceptions the page addresses

- Recombinant DNA is simply mixing DNA. Cutting, joining, vector transfer and host use have distinct roles.
- A transgenic organism is just selectively bred. It contains directly introduced DNA.
- Any restriction enzyme works for any join. The page calls for complementary ends on fragment and vector.

## 7. Practical or real-world examples used

Human insulin production in bacteria; transgenic pest-resistant crops; plasmids; restriction enzymes; ligase; PCR at about 95 degrees Celsius for denaturing; gel electrophoresis. The page explains techniques but assigns no hands-on experiment.
