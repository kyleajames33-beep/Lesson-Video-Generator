## 3. Key ideas in order

1. The Five Components: Every feedback system, biological or mechanical, is built from the same five parts arranged in the same order, learn them once and you can read any example.
2. A Worked Example: Getting Cold: Walking through a single example shows how the abstract five-part framework becomes a concrete chain of events in the body.
3. Why the Components Must Connect: Each component does a job no other can do, so removing any one breaks the system, which is why a "typical feedback system" always lists all five.
4. Feedback control everywhere, from cruise control to insulin pumps: The same five-part logic runs a car's cruise control, a fridge thermostat and an aircraft autopilot, and, life-changingly, an artificial pancreas.

## 4. Key terms

- Homeostasis: The maintenance of a stable internal environment despite changes outside the body.
- Stimulus: A change in the internal or external environment that disturbs the set level (e.g. a drop in temperature).
- Receptor: A structure that detects the stimulus and sends a message to the control centre.
- Control centre: The part (often the brain) that receives the message, compares it to the set point and decides the response.
- Effector: A muscle or gland that carries out the response ordered by the control centre.

## 6. Misconceptions the page addresses

- Misconceptions To Fix watch out ✗ Wrong: Homeostasis means the body keeps everything perfectly constant and unchanging. ✓ Right: Homeostasis keeps conditions within a narrow range around a set point, values constantly fluctuate slightly and are corrected.
