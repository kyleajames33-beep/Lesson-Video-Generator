## 3. Key ideas in order

1. Sequences Record Ancestry: When two species split from a common ancestor, their DNA slowly accumulates separate mutations, so the longer ago they split, the more their sequences differ.
2. The Investigation, Counting Differences: The method is straightforward: take the same gene or protein from each species, line them up, count the positions that differ for each pair, and record the totals in a table.
3. Reading the Tree & Its Limits: A phylogenetic tree turns the pattern of differences into branch points: the more similar two species are, the more recently their branches join.
4. Why this matters: tracing viruses and classifying life: The same sequence-comparison method you used drives front-line science.

## 4. Key terms

- Sequence alignment: Lining up the same gene or protein from different species position by position so they can be compared.
- Phylogenetic tree: A branching diagram showing inferred evolutionary relationships; shared branch points represent common ancestors.
- Common ancestor: A species from which two or more later species both descend.
- Conserved sequence: A part of a gene or protein that changes very little over time because it is essential to function.
- Molecular clock: The idea that mutations accumulate at a roughly steady rate, so the number of differences estimates time since divergence.
