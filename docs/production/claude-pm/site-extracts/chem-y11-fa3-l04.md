## 3. Key ideas in order

1. Precipitation Reactions and Solubility Rules: A precipitation reaction happens when two aqueous solutions are mixed and the dissolved ions rearrange so that one new combination is insoluble, it can no longer stay dissolved, so it falls out of solution as a solid.
2. Full Molecular, Full Ionic and Net Ionic Equations: There are three ways to write a precipitation reaction, each one peeling back a layer until only the ions that truly react remain.
3. Predicting Precipitates in the Lab: To predict the products in the lab, imagine the two compounds swapping partners, then check each new compound against the solubility rules, if one is insoluble, a precipitate forms.

## 4. Key terms

- Precipitate: An insoluble solid that forms and separates out when two aqueous solutions are mixed, shown with the state symbol (s).
- Solubility rules: A set of generalisations that predict whether a given ionic compound is soluble or insoluble in water.
- Spectator ion: An ion present on both sides of a reaction that does not take part in forming the precipitate, so it cancels from the net ionic equation.
- Net ionic equation: An equation showing only the ions that actually combine to form the precipitate, with spectator ions removed.
