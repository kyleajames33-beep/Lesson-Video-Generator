## 3. Key ideas in order

1. Three Factors That Change Enzyme Efficiency: An enzyme's efficiency, how fast it converts substrate, depends strongly on three measurable conditions: temperature, pH and substrate concentration.
2. Planning a Fair Test: A valid enzyme experiment changes only one factor (the independent variable), measures the rate (the dependent variable), and keeps every other factor constant (controlled variables).
3. Reliability, Validity and Improving the Test: A good experiment is both valid (it tests the intended variable) and reliable (it gives consistent results when repeated), and a control group shows the effect is real.
4. Why your body runs a fever: The same temperature sensitivity you test in this practical is why a high fever is dangerous: human enzymes have an optimum near 37 °C, and a body temperature above about 42 °C begins to denature them, which can be life-threatening.

## 4. Key terms

- Independent variable: The one factor you deliberately change (e.g. temperature).
- Dependent variable: The factor you measure as the outcome (e.g. rate of oxygen produced).
- Controlled variable: A factor kept the same throughout so it cannot affect the result.
- Validity: Whether the experiment actually tests what it claims to, needs only one variable changed.
- Reliability: Whether repeated trials give consistent results; improved by repeating and averaging.
