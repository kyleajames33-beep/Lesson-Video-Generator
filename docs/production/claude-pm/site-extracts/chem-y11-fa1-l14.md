## 3. Key ideas in order

1. Atomic and Ionic Radius: Atomic size is set by a tug-of-war: the nucleus pulls electrons in, while each extra shell pushes the outer electrons further out.
2. First Ionisation Energy: First ionisation energy measures exactly how firmly an atom grips its most loosely held electron, so it tracks the same nuclear pull that controls size, but in the opposite direction.
3. Electronegativity and Plotting the Data: Electronegativity rates how greedily an atom attracts shared bonding electrons, and once again the same two causes, effective nuclear charge and shell number, set the pattern.

## 4. Key terms

- Atomic radius: A measure of the size of an atom, typically the distance from the nucleus to the outermost electrons, in picometres (pm).
- Effective nuclear charge: The net positive pull felt by an outer electron, after inner electrons partly shield it from the nucleus.
- First ionisation energy: The energy needed to remove the most loosely held electron from one mole of gaseous atoms.
- Electronegativity: A measure of an atom's ability to attract the shared electrons in a chemical bond (Pauling scale).

## 6. Misconceptions the page addresses

- Misconceptions To Fix watch out ✗ Wrong: More protons and electrons must make an atom bigger. ✓ Right: Across a period, electrons go into the same shell while protons increase, so the stronger pull draws the shell inward and the atom gets smaller. ✗ Wrong: Ionisation energy and electronegativity follow the same direction as atomic radius. ✓ Right: They run opposite to atomic radius.
