## 3. Key ideas in order

1. The Method & the Lincoln Index: If marked animals mix evenly back into the population, the fraction of marked animals you find in a second catch equals the fraction of the whole population that is marked.
2. Modelling It & Doing the Calculation: A bag of identical beans models a population: you "mark" some by swapping them for a different colour, mix, then sample again.
3. Assumptions & Sources of Error: The Lincoln index is only valid if the marked animals truly behave like an unbiased random sample of the population the second time around.
4. Why this matters: counting wildlife and fish stocks: Mark-release-recapture is used worldwide to estimate populations that cannot be counted directly, from tagging fish to set sustainable catch limits, to banding birds and microchipping threatened mammals like quolls.

## 4. Key terms

- Mark-release-recapture: A method to estimate the size of a mobile-animal population by marking, releasing and re-sampling.
- Lincoln index: The formula N = (M × C) ÷ R used to estimate total population size.
- M (first capture): The number of individuals caught, marked and released in the first sample.
- C (second capture): The total number of individuals caught in the second sample.
- R (recaptured): The number in the second sample that carry a mark from the first.
