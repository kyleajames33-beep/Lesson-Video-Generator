## 3. Key ideas in order

1. DNA sequencing determines the exact order of nucleotide bases in a DNA region.
2. When the sequence is known, specific mutations, SNPs and inherited variants can be identified directly.
3. DNA profiling compares patterns at selected variable DNA regions to distinguish or relate samples; it does not normally read the full base order.
5. In Module 5, both technologies investigate inheritance patterns, relatedness and disease variants across groups, not only forensic cases.
6. A profile match rests on how common each pattern is in the population, so a random match is "astronomically low", without the samples being identical everywhere.

## 4. Key terms

- DNA sequencing: Determining the order of nucleotide bases in a DNA sequence.
- DNA profiling: Comparing patterns at selected DNA regions to distinguish or relate samples.
- Base order: The exact sequence of A, T, C and G nucleotides in DNA.

## 6. Misconceptions the page addresses

- "A DNA profile reveals the complete base order of the whole genome." Page: false; profiling compares marker patterns.
- "DNA sequencing reads the exact sequence of bases directly from chromosomes." Page: sequencing works on short fragments, and "the chromosome itself is never read end-to-end in a single pass".
- "A profile match means the samples are identical everywhere." Page: the match means a random person sharing that combination is "astronomically low", not that the samples are identical everywhere in the genome.

Possible site errors: (a) "Pitchfork's 1986 conviction was the world's first criminal conviction using DNA evidence": 1986 was the year of the murders and the testing; Pitchfork's conviction followed his guilty plea in January 1988. (b) The Compare model answer says both technologies "begin with DNA extraction and amplification by PCR": the 1986 RFLP method on the page cut DNA with restriction enzymes and did not use PCR, so the claim fits STR profiling and sequencing only. (c) "1 in 40 billion" and "courts in over 50 countries" have no source on the page and are not checked.
