## 3. Key ideas in order

1. The three most common ICE errors are wrong stoichiometric ratios in the Change row, reporting x instead of the equilibrium value, and not verifying.
2. The ICE table works like a bank account: every equilibrium value must be positive.
3. The screen Keq/[initial] < 0.05 is “only a rough screen”; the decisive test comes after solving.
4. Post-check: if x/[initial] × 100 is below 5%, the simplification stands; otherwise solve the full quadratic.
5. With non-zero initial products, calculate Q first: Q < Keq shifts right, Q > Keq shifts left.
6. For ax² + bx + c = 0, choose the root that gives all positive equilibrium values.

## 4. Key terms

- ICE table: “A systematic tool for calculating equilibrium concentrations from initial conditions and Keq.”
- Quadratic equation: “Arises when the small-x approximation is not valid; solved using the quadratic formula.”
- 5% rule (post-check): “The decisive test, applied after solving: if x/[initial] × 100 < 5%, the small-x assumption was valid.”
- Keq vs Q comparison: “If Q < Keq, reaction proceeds forward; if Q > Keq, reverse; if Q = Keq, at equilibrium.”
- Multiple equilibria: “When a substance participates in two simultaneous equilibria, both must be satisfied simultaneously.”
- Concentration unit: “mol L⁻¹ (molarity); all ICE table values must be in these units for Keq calculations.”

## 5. Worked examples

- Think First: 0.200 mol H₂ and I₂ in 1.00 L at 430°C, Keq = 54.3. The student wrote +x for HI and reported [HI] = 0.176 mol/L. Correct: x = 0.157, [HI] = 0.315 mol/L, [H₂] = [I₂] = 0.0427 mol/L.
- Worked Example 1 (assumption valid): N₂ + O₂ ⇌ 2NO, Keq = 1.0 × 10⁻³⁰ at 25°C, [N₂] = 0.780, [O₂] = 0.210 mol/L. x = 2.024 × 10⁻¹⁶; [NO] = 4.05 × 10⁻¹⁶ mol/L.
- Worked Example 2 (quadratic required): 0.500 mol PCl₅ in 1.00 L at 250°C, Keq = 0.041. Screen: 8.2% > 5%. x = 0.124; [PCl₅] = 0.376 mol/L; [PCl₃] = [Cl₂] = 0.124 mol/L.
- Worked Example 3 (non-zero products): H₂ + I₂ ⇌ 2HI at 430°C, all three at 0.100 mol/L. Q = 1.00 < 54.3, so the shift is right. x = 0.0680; [HI] = 0.236 mol/L; verified 54.4 ≈ 54.3.

## 6. Misconceptions the page addresses

- Change row written as ±x for every species; for N₂ + 3H₂ ⇌ 2NH₃ the change is N₂ −x, H₂ −3x, NH₃ +2x.
- “The simplifying assumption is always valid when Keq < 1.” SAQ 2: with Keq = 0.4 and [initial] = 0.100, Keq/[initial] = 400%.
- Choosing the larger quadratic root: the page's True/False item has the answer False.
