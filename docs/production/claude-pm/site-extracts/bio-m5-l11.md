## 3. Key ideas in order

1. mRNA carries the code but cannot become a protein by itself; ribosomes and tRNA are also needed.
2. The ribosome reads mRNA in codons, three bases at a time; it interprets the message but does not create it.
3. The ribosome is built from proteins and rRNA, and rRNA catalyses the joining of amino acids.
4. tRNA carries a specific amino acid at one end and an anticodon at the other.
5. Codon and anticodon pair antiparallel, so the codon order sets the amino acid order.
6. Peptide bonds join adjacent amino acids; translation starts at AUG (methionine) and ends at a stop codon.
7. Insulin is a protein product that depends on accurate translation.

## 4. Key terms

- Translation: The process of using the mRNA code to assemble a polypeptide.
- rRNA: Ribosomal RNA, which forms the structural and catalytic core of the ribosome.
- Anticodon: A three-base sequence on tRNA that pairs antiparallel with a complementary codon on mRNA.
- Start codon: AUG, which begins translation and codes for methionine.
- Stop codon: UAA, UAG or UGA; a codon that ends translation (no amino acid is added).

## 5. Worked examples

- Activity 1: mRNA codons "A U G G A A"; page answer: possible tRNA anticodons "U A C C U U"; the molecule carrying amino acids is tRNA.
- Antiparallel example: "a 5'-GCA-3' codon is read by a 3'-CGU-5' anticodon".
- Streptomycin: first isolated by Waksman in 1943; by 1962 it was shown to bind the 30S subunit of bacterial ribosomes (70S = 30S + 50S) and cause codon misreading; eukaryotic ribosomes are 80S (40S + 60S).
- Activity 2 model answer: a wrong amino acid sequence may make insulin "fold or function incorrectly".

## 6. Misconceptions the page addresses

- "Translation occurs in the nucleus where the DNA is." Page: translation occurs in the cytoplasm, at ribosomes; mRNA must be exported first.
- "There is only one kind of tRNA." Page: there are many tRNA species, each matched to one amino acid.
- Do not mix codons with anticodons, or say that mRNA carries amino acids.
- True/false (false): "The start codon AUG codes for the amino acid tryptophan."

Possible site errors: Activity 1 gives the anticodon for GAA as "CUU" with no direction. Read in the same direction it is the complement; the antiparallel anticodon for 5'-GAA-3' is 3'-CUU-5' (written 5'-UUC-3'), which the page itself describes as antiparallel.
