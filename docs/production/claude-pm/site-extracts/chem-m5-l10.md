## 2. Syllabus content covered

“perform calculations to find the value of Keq and concentrations of substances within an equilibrium system, and use these values to make predictions on the direction in which a reaction may proceed (ACSCH096)”

## 3. Key ideas in order

1. Keq is found by writing the Keq expression first, then substituting equilibrium concentrations with the correct powers.
2. An ICE table (initial, change, equilibrium) finds the missing equilibrium concentrations.
3. The Change row uses stoichiometric ratios, not ±x for every species; equilibrium = initial + change.
4. Verification: substituting the equilibrium values back into Keq must reproduce the given Keq.
5. With Keq and initial concentrations given, the change is written in x and the expression is solved.
6. Colourimetry: a calibration curve gives [NO₂], an ICE table gives [N₂O₄], then Keq.
7. The page treats Keq as “dimensionless throughout this course, because the concentration values stand in for activities.”

## 4. Key terms

- ICE table: “Initial, Change, Equilibrium, a tabular method for tracking concentration changes as equilibrium is established.”
- Initial concentration: “The starting molar concentration of each species before any reaction occurs.”
- Change row: “The stoichiometric change in concentration as the reaction proceeds towards equilibrium (uses variable x).”
- Equilibrium concentration: “The final molar concentration of each species at equilibrium; substituted into Keq expression.”
- Keq calculation: “Dividing the equilibrium concentrations of products by reactants, each raised to stoichiometric powers.”
- Assumption (small-x): “If Keq is very small, x is negligible compared to initial concentrations, simplifying the algebra.”

## 5. Worked examples

- Direct substitution: 2SO₂ + O₂ ⇌ 2SO₃ at 600°C, [SO₂] = 0.200, [O₂] = 0.100, [SO₃] = 0.350 mol/L. Keq = (0.350)² / ((0.200)²(0.100)) = 30.6.
- Worked Example 1: PCl₃ + Cl₂ ⇌ PCl₅ at 250°C, [PCl₃] = 0.130, [Cl₂] = 0.045, [PCl₅] = 0.380 mol/L. Keq = 65.0.
- Worked Example 2: 1.00 mol SO₃ in 1.00 L at 700°C, 2SO₃ ⇌ 2SO₂ + O₂, [SO₃]eq = 0.780 mol/L. Change: SO₃ −0.220, SO₂ +0.220, O₂ +0.110. Keq = 8.75 × 10⁻³.
- Forward ICE: H₂ + I₂ ⇌ 2HI, Keq = 54.3 at 430°C, [H₂] = [I₂] = 0.100 mol/L. Keq = 4x²/(0.100−x)²; x = 0.0787. Equilibrium: [H₂] = [I₂] = 0.0213, [HI] = 0.157 mol/L. Verified: 54.6 ≈ 54.3.

## 6. Misconceptions the page addresses

- Writing +x for HI: a student using +x “would report [HI] = 0.0881 mol/L”; the correct change is +2x.
- Reporting x instead of the equilibrium-row value, or squaring the whole bracket instead of each concentration.
- Skipping verification: “Always substitute E-row values back into Keq.”

Possible site errors:
- The Keq expression for N₂O₄ ⇌ 2NO₂ is [NO₂]²/[N₂O₄] (Δn = +1), which carries units (mol L⁻¹). The page calls Keq dimensionless without stating a basis.
- Extended Response (c): 1.20 mol H₂ and I₂ in 2.00 L with [HI] = 0.480 mol/L gives Keq = (0.480)²/(0.360)² = 1.78, not a value to compare with 54.3 as the question asks.
