## 3. Key ideas in order

1. DNA nucleotides contain sugar, phosphate and a nitrogenous base; the sugar-phosphate backbone supports inward-facing complementary bases.
2. A pairs with T and C with G, so each strand specifies a complementary strand and can act as its template.
3. Semiconservative replication separates the original strands and builds new partners, producing two molecules with one original and one new strand each.
4. Helicase separates strands, polymerase adds nucleotides only 5′ to 3′, and ligase joins lagging-strand Okazaki fragments.
5. Accurate replication preserves hereditary information; errors can change DNA and affect proteins or cell behaviour.
6. Extended responses connect base pairing, intact strand separation and retained original strands to accuracy, then describe nucleotide composition and bonding.

## 4. Key terms

- Nucleotide: The building block of DNA, consisting of a sugar, phosphate group and nitrogenous base.
- Double helix: The twisted ladder structure formed by two DNA strands.
- Complementary base pairing: Specific pairing of bases: adenine with thymine, and cytosine with guanine.
- Hydrogen bonds: Weak bonds between complementary bases that help hold the two DNA strands together.
- Semiconservative replication: DNA replication in which each new DNA molecule contains one original strand and one newly synthesised strand.
- Template strand: An original DNA strand used to guide formation of a new complementary strand.

## 5. Worked examples

Core example: template A-T-C-G produces T-A-G-C.

Activity 1 givens and answers:

- A T C G A → T A G C T.
- C G T T A C → G C A A T G.
- G A A T C C → C T T A G G.

Activity 2 answers: separation exposes each original template; each guides formation of a complementary strand; each daughter molecule contains one old and one new strand.

The Describe walkthrough specifies deoxyribose, phosphate and one of four bases; covalent phosphodiester bonds form the backbone; A-T has two hydrogen bonds and G-C three.

Explain (6 marks) answer: complementary pairing determines which base is added; weak hydrogen bonds allow intact strands to separate; each daughter molecule retains an original template strand. Describe is worth 4 marks.

## 6. Misconceptions the page addresses

- Original DNA is discarded or irrelevant: original strands are templates.
- Replication makes two entirely new strands in each molecule: each molecule retains one original strand.
- DNA and RNA have identical structures: DNA has deoxyribose and thymine; RNA has ribose and uracil.
- DNA strands are identical: they are complementary and antiparallel.
- Polymerase works in both directions: new strands are built only 5′ to 3′.
