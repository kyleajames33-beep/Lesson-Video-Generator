## 3. Key ideas in order

1. Measuring the Rate with Oxygen Bubbles: Because oxygen is a product of photosynthesis, the faster oxygen is released, the faster photosynthesis must be occurring, so counting oxygen gives a direct measure of the rate.
2. Planning a Fair Test: A fair test changes one condition at a time and holds all others constant, so any change in oxygen output can confidently be attributed to that one condition.
3. Predicting the Outcome from the Model: A good practical does not just observe, it predicts, so the data can confirm or challenge the underlying model.
4. How crop scientists optimise glasshouses: The same predict-change-measure cycle you practise with pondweed is exactly how agricultural scientists fine-tune commercial glasshouses.

## 4. Key terms

- Independent variable: The single factor the experimenter deliberately changes (e.g. lamp distance / light intensity).
- Dependent variable: The factor measured to see the effect (e.g. bubbles of oxygen per minute).
- Controlled variable: A factor kept constant so it cannot affect the result (e.g. temperature, CO₂ level, same pondweed).
- Prediction: A statement of the expected result, justified by a scientific model, here, the limiting-factor model.
- Reliability: The consistency of results when the measurement is repeated; improved by repeats and averaging.
