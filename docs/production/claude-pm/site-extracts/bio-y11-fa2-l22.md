## 3. Key ideas in order

1. What Negative Feedback Does: Negative feedback keeps a variable steady by detecting when it drifts away from its set point and then triggering a response that pushes it back the other way.
2. Constructing the Loop Diagram: A negative feedback diagram is a closed loop: each component passes information to the next, and the loop closes when the response returns the variable to the set point.
3. Interpreting a Loop, Thermoregulation: A single negative feedback system corrects a variable whether it rises or falls, because the response always opposes the change in whichever direction it occurs.
4. When negative feedback can't keep up: heatstroke: Negative feedback is powerful but not unlimited.

## 4. Key terms

- Homeostasis: The maintenance of a stable internal environment within narrow limits, despite changes outside the body.
- Set point: The normal value (or narrow range) that a variable such as body temperature is held around.
- Negative feedback: A control loop in which the response reverses (opposes) the change that triggered it, returning the variable toward the set point.
- Effector: A muscle or gland that carries out the response (e.g. sweat glands, skeletal muscle).
- Control centre: The part (often the brain, e.g. the hypothalamus) that compares the value to the set point and triggers a response.
