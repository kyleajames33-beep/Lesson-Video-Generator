## 3. Key ideas in order

1. The Temperature Curve: As temperature rises, enzyme activity increases to an optimum, then drops sharply because the enzyme denatures.
2. The pH Curve: Enzyme activity peaks at an optimum pH and falls away on either side, because pH values too far from the optimum also denature the enzyme.
3. The Substrate-Concentration Curve: As substrate concentration increases, the rate rises and then plateaus, not because the enzyme is damaged, but because all the active sites become saturated.
4. Enzymes built for extreme places: The optimum on these graphs is not fixed for all life.

## 4. Key terms

- Optimum: The temperature or pH at which an enzyme works fastest.
- Denaturation: A permanent change in an enzyme's shape (including its active site) so it can no longer bind substrate.
- Saturation: The point where every active site is occupied, so adding more substrate cannot raise the rate.
- Rate of reaction: How fast substrate is converted to product, usually plotted on the y-axis.
- Plateau: A flat section of a graph where the value stops changing.

## 6. Misconceptions the page addresses

- Misconceptions To Fix watch out ✗ Wrong: The substrate-concentration graph levels off because the enzyme has denatured. ✓ Right: The substrate graph plateaus because the enzyme is saturated, all active sites are busy, so adding more substrate can't speed things up.
