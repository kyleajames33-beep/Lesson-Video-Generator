## 3. Key ideas in order

1. Ksp is Keq for a sparingly soluble ionic solid dissolving; the solid is excluded and there is no denominator.
2. Stoichiometric coefficients become powers in the Ksp expression.
3. Molar solubility (s) is found from Ksp with an ICE table in which the initial ion concentrations are zero.
4. For a 1:1 salt, Ksp = s², so s = √Ksp.
5. For CaF₂, [F⁻] = 2s, so Ksp = s(2s)² = 4s³ and s = ∛(Ksp/4).
6. Ksp can be found from a measured s by the same steps in reverse.
7. Ksp values can be compared directly only for compounds with the same formula type: CaF₂ has a smaller Ksp than AgCl but a larger molar solubility.

## 4. Key terms

- Solubility product (Ksp): "The equilibrium constant for the dissolution of a sparingly soluble ionic compound."
- Molar solubility (s): "The number of moles of a sparingly soluble compound that dissolves per litre of solution."
- Relationship between s and Ksp: "For MₓAᵧ(s) ⇌ xM⁺(aq) + yA⁻(aq): Ksp = (xs)^x × (ys)^y."
- Comparing Ksp values: "A larger Ksp indicates greater solubility; comparison is only valid for compounds with the same ion ratio."

## 5. Worked examples

**Worked Example 1 (Apply/Analyse).** The molar solubility of Ag₂SO₄ is 7.60 × 10⁻³ mol/L at 25°C. (a) Write the dissolution equation. (b) Express the ion concentrations in terms of s. (c) Calculate Ksp.
Answer: (a) Ag₂SO₄(s) ⇌ 2Ag⁺(aq) + SO₄²⁻(aq). (b) [Ag⁺] = 2s = 1.520 × 10⁻² mol/L; [SO₄²⁻] = s = 7.60 × 10⁻³ mol/L. (c) Ksp = 1.76 × 10⁻⁶.

**Worked Example 2 (Analyse/Evaluate).** (a) Molar solubility of PbSO₄ (Ksp = 1.6 × 10⁻⁸) and AgBr (Ksp = 5.0 × 10⁻¹³). (b) Can the Ksp values be compared directly? (c) Which is less soluble?
Answer: (a) s(PbSO₄) = 1.27 × 10⁻⁴ mol/L; s(AgBr) = 7.07 × 10⁻⁷ mol/L. (b) Yes, both are 1:1. (c) AgBr is less soluble.

## 6. Misconceptions the page addresses

- Including the solid: "Ksp = [Ag⁺][Cl⁻]/[AgCl], wrong." Page: no denominator.
- For CaF₂, writing Ksp = s × s² = s³. Page: the coefficient 2 must sit inside the squared bracket, and the error is "approximately 1.59× too large".
- "CaF₂ (Ksp = 3.9 × 10⁻¹¹) is less soluble than AgCl ... because its Ksp is smaller." Page: "Wrong, CaF₂ is actually MORE soluble than AgCl at 25°C."
- Comparing Ksp directly across formula types. Page: "Never compare Ksp of AgCl (1:1) with CaF₂ (1:2)... without calculating molar solubility first."
