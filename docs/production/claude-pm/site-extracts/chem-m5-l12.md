## 2. Syllabus content covered

“perform calculations to find the value of Keq and concentrations of substances within an equilibrium system, and use these values to make predictions on the direction in which a reaction may proceed (ACSCH096)”

## 3. Key ideas in order

1. “Keq tells you where a reaction is heading. Q tells you where it is right now.”
2. Q uses the same expression as Keq, with current concentrations instead of equilibrium concentrations.
3. Q < Keq shifts the system right; Q > Keq shifts it left; Q = Keq means no net shift.
4. Five steps: write the expression, identify the current concentrations, calculate Q, compare with Keq, state the direction.
5. Adding a reactant or removing a product lowers Q and shifts right; adding a product or removing a reactant raises Q and shifts left.
6. In an ammonia reactor, condensing NH₃ out lowers Q below Keq, so the forward reaction restarts.
7. Q starts at 0 from pure reactants and at ∞ from pure products, then converges on Keq.

## 4. Key terms

- Reaction quotient (Q): “The ratio of product to reactant concentrations at any instant, using the same form as Keq.”
- Q vs Keq comparison: “If Q < Keq: reaction proceeds forward (more products form); Q > Keq: reverse; Q = Keq: at equilibrium.”
- Predicting shift direction: “Comparing Q to Keq allows prediction of which direction the reaction must proceed to reach equilibrium.”
- Non-equilibrium state: “Any mixture where Q ≠ Keq; concentrations are still changing.”
- Reaction progress: “As a reaction proceeds from any starting point, Q changes until it equals Keq at equilibrium.”
- Effect of dilution on Q: “Diluting all species simultaneously may increase or decrease Q depending on the mole ratio in Keq.”

## 5. Worked examples

- Think First: Keq = 50, Q = 120 at 25°C. Q > Keq, so the reaction shifts left.
- Five-step example: 2SO₂ + O₂ ⇌ 2SO₃, Keq = 270 at 700°C. [SO₂] = 0.40, [O₂] = 0.30, [SO₃] = 0.20 mol/L. Q = 0.833 < 270, so the system shifts right.
- Worked Example 1: N₂ + 3H₂ ⇌ 2NH₃, Keq = 0.500 at 400°C. [N₂] = 0.200, [H₂] = 0.300, [NH₃] = 0.150 mol/L. Q = 4.17 > 0.500, so the system shifts left.
- Worked Example 2: H₂ + I₂ ⇌ 2HI, Keq = 54.3 at 430°C. At [H₂] = [I₂] = 0.020 and [HI] = 0.148 mol/L, Q = 54.8 ≈ 54.3 (equilibrium). Adding 0.030 mol/L HI gives Q = 79.2 > 54.3, so the system shifts left.

## 6. Misconceptions the page addresses

- “Q and Keq are calculated using different formulas.” Wrong: same expression, different concentrations.
- “Q and Keq are equal when the same concentrations are used.” The page calls this circular: Q = Keq only at equilibrium.
- “Q < Keq therefore shifts left.” Wrong: Q < Keq means the shift is right.
- “Removing the ammonia increases Keq, so more forms.” Removing ammonia changes Q, not Keq.

Possible site errors:
- The five-step example gives Keq = 270 at 700°C for 2SO₂ + O₂ ⇌ 2SO₃. Short answer 1 gives Keq = 280 at 700°C for the same equilibrium.
- Lesson 10 Worked Example 2 gives 8.75 × 10⁻³ at 700°C for 2SO₃ ⇌ 2SO₂ + O₂. Its inverse, about 114, matches neither 270 nor 280.
- Short answer 3 gives Keq = 5.67 × 10⁶ at 25°C for CO + 3H₂ ⇌ CH₄ + H₂O. Standard free energies of formation (about −142 kJ mol⁻¹ with H₂O(g)) give Keq of order 10²⁴ to 10²⁵ at 25°C.
