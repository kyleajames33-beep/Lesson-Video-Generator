# YouTube description template

Start every new upload description with this line, replacing the placeholders with the checked lesson path:

`Full lesson, notes and practice questions: https://hscscience.com.au/subjects/<subject>/year12/<module>/lessonNN`

Use the clean URL without `.sa`. Check that `C:/Users/kygs/hscscience/subjects/<subject>/year12/<module>/lessonNN.sa.html` exists and that the lesson design and site extract match the video. For a practice or practical video, link the lesson it practises. If the video covers two lessons, put each link on its own line. Then leave a blank line and continue with the video's existing description, including chapters, course line, syllabus dotpoint, official course link, prerequisite, next lesson and hashtags.
