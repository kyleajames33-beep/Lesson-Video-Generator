**Verdict: pass after blockers.** Two blockers, nine should-fix items and several notes. ## Memory aid check

Aid: "Copy, share, split" with the trap "Fission makes more cells. Conjugation makes different cells, not more." Under the stated assumptions (bacterium, baker's yeast budding, amoeba, paramecium; not spores, not sexual) the order is right and it works for new asexual single-celled cases: it identifies the missing step in item one, and it is easy to reconstruct. It breaks on item two if left alone, because conjugation copies DNA and shares it (finding 7). With the repair ("conjugation copies and shares, but never splits, so it makes no new cell") the aid separates reproduction from DNA transfer. The wording "makes different cells" must change to "changes cells that already exist" (finding 7). The aid does not claim anything about mitosis, nuclear stages or spores and should not be extended to them. For a bud, "split" means the bud breaks away; for Acineta, the bud is released. State these two in the aid check only.

## Key notes (suggested wording)

1. Binary fission: a cell copies its DNA, the copies move apart and the cell splits into two. It is asexual, so the new cells are clones of the parent, apart from rare copying errors. Bacteria, amoebae and paramecia reproduce this way.
2. Budding: the DNA is copied, one copy moves into a bud, and the bud breaks away as a new cell. Baker's yeast usually reproduces this way, and so do a few protists such as Acineta.
3. Copy, share, split. The DNA must be copied before the cell splits, or one new cell would have none and no instructions.
4. Under good conditions some bacteria divide every 20 minutes. Starting from one cell, the number after n doublings is 2 to the power n. Running out of food, or cold, slows or stops this.
5. Conjugation passes DNA from one existing bacterium to another. It changes cells that already exist, but makes no new cell, so it is not reproduction.

Aid (large): *Copy, share, split.*
