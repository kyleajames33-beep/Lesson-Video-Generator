## Findings

### S1. Should fix: the general formulas need "open chain, one multiple bond" in learner copy

- Exact text (scene 9): "To tell them apart, use the molecular formula: C n H two n for an alkene, and C n H two n minus **two** for an alkyne." Key note 4: "use the formula (alkene CnH2n, alkyne CnH2n−2)".
- Problem: C₄H₆ (buta-1,3-diene) and C₆H₁₀ (cyclohexene) decolourise bromine water and fit CnH2n−2 but are not alkynes. The design's own correction 3 records this ambiguity on the site; the video must not repeat it. This caveat meets the AGENTS rule (its omission teaches a wrong idea).
- Replacement (scene 9): "To tell them apart, use the molecular formula. For an open-chain hydrocarbon with one multiple bond, C n H two n is an alkene, and C n H two n minus **two** is an alkyne."
- Replacement (key note 4): "Alkenes and alkynes decolourise bromine water at room temperature without UV light; alkanes don't. The test shows a multiple bond, not which one. For an open-chain hydrocarbon with one multiple bond, use the formula: alkene CnH2n, alkyne CnH2n−2."

### S2. Should fix: "quickly" overstates alkyne reactivity with bromine

- Exact text (scene 9): "Alkenes **and** alkynes both decolourise it quickly in the dark, because both can add." Key note 4: "decolourise bromine water quickly in the dark".
- Evidence: alkynes add bromine much more slowly than alkenes (Fahey's review: about 100 to 50,000 times slower in acetic acid). Author note (g) already concedes "often more slowly".
- Replacement: "Alkenes **and** alkynes both decolourise it at room temperature, without UV light, because both can add." Key note 4 as in S1.

### M1. Minor: the second HBr step disagrees with the linked site lesson

- Exact text (scene 8): "a second H Br can give **two** possible dibromoethanes."
- Problem: under ordinary (ionic) conditions the product is 1,1-dibromoethane; site lesson 7 says full hydrohalogenation gives the geminal dihalide. Naming 1,2-dibromoethane as a possible product is structurally defensible and matches c04a's propene treatment, but a student who checks the linked lesson sees a contradiction, and the sentence adds a second idea to scene 8.
- Recommended: take the author's Open-decisions fallback. Replacement: "Hydrogen bromide works the same way. The first step gives bromoethene, and a second H Br adds in the same way, giving a dibromoethane." Show only CH₃CHBr₂, named "1,1-dibromoethane", not labelled major. Author note (e) stays as written. If the root prefers the c04a parallel, keep the design and add to author note (e): "Under ionic conditions the observed product is 1,1-dibromoethane; 1,2- is named only as a structural possibility."

### M2. Minor: site correction 3 should also name MC answer 4

- Add to correction 3: "The same claim appears in Multiple Choice answer 4: 'Two sequential Br₂ additions (consuming 2 equivalents) confirms two pi bonds → alkyne.' Correct: '... confirms two multiple bonds' worth of addition (a C≡C, or two C=C); with an open chain and one multiple bond, an alkyne.'"

### M3. Minor: author note on swap-docker order

- Add to author note (b): "The swap docker shows the overall bookkeeping (one H out, one Br in, H with the other Br). In the real chain, a Br atom removes the H first (giving HBr), then the alkyl radical takes a Br from Br₂. The grey 'overall result' tag (learning M5) keeps the animation from implying a sequence."
