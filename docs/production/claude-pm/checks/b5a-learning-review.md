# B5a learning review: mitosis (how a cell keeps its chromosomes)

**Verdict: pass after blockers.** Two blockers, fourteen should-fix items and several notes. The design has real strengths: a concrete hook that poses one question; one model cell with four chromosomes drawn the same way throughout; causes before names for the stages (why the chromosomes coil, what the fibres do, what separates and where it goes); a tracker built one stage at a time with the human row derived from the same four statements; the colour rule (plum and teal for the two sets, a cream centromere disc on every chromosome, never colour only); an unseen two-item attempt with all conditions on screen and a 90 second countdown; and feedback that names the wrong chains. The blockers are both vocabulary collisions that make a correct statement in the lesson's own words false for its own example. Second, scene 6a says the fibres pull "one of each pair to each end" after scene 2a has taught "homologous pair", which is the meiosis I picture and false for mitosis. ## Memory aid check

**IPMAT.** Correct for the order of the four mitosis steps once I is read as "before mitosis". It supports a new case (ordering a shuffled list of events, as the site's activity 1 does). It fails if the student reads five stages of mitosis or places cytokinesis as a fifth step: finding 13 puts the caveat in speech, not only on a tag. It says nothing about prometaphase, which is not named in the course. The keyword under each letter carries the meaning, so the aid comes after the stages (scene 9), which is right. "Packs" maps to coiling; the repair says "coils".

**Count the centromeres, not the arms.** True for every diagram in this lesson (one cream disc per chromosome, replicated or not, and one per separated chromatid at anaphase). It does not tell a student whether a chromosome is copied (the lesson says so in 2c). "Arms" is the wrong word (finding 5): say "chromatids". The rule fails if a diagram hides a centromere, but none here does.

**"Mitosis keeps the number. Meiosis halves it."** Used only as the closing handoff and phrased "one set, not two". True for the gamete formation the next video teaches. Keep the learner wording "the same number as the parent cell".

**"Copy, share, split".** Recalled from B2c; maps to S phase, mitosis, cytokinesis. It breaks for a bacterium (no mitosis), which 6c now says. Fine.

## Key notes (suggested wording, about 190 words, hold about 75 s)

1. A chromosome is DNA wound with proteins: one long DNA molecule before copying, two identical ones (sister chromatids) after. A set is one of each kind of chromosome. A diploid cell has two sets, one from each parent; a haploid cell has one. A human body (somatic) cell has 46 chromosomes in two sets of 23; a gamete has 23.
2. DNA is copied in interphase (S phase), before mitosis. A copied chromosome has two identical sister chromatids joined at a centromere. It is still one chromosome. Count centromeres, not chromatids.
3. Prophase: chromosomes coil, the nuclear envelope breaks down, the spindle forms. Metaphase: chromosomes line up in the middle, each on its own. Anaphase: centromeres split and sister chromatids are pulled to opposite ends; each is now a chromosome. Telophase: chromosomes uncoil and new nuclei form. Cytokinesis then splits the cytoplasm.
4. Each new cell gets one copy of every chromosome, so, barring errors, it has the same chromosome number and genetic information as the parent. Human cell: 46 chromosomes, 92 chromatids after copying, 92 chromosomes in anaphase, 46 in each new cell. The number is not halved. To explain: copying makes sister chromatids, fibres from opposite ends attach to them, a checkpoint confirms this before anaphase, and they are pulled apart.
5. Mitosis is used for growth, repair, replacing worn-out cells and asexual reproduction in organisms with a nucleus (yeast, cuttings). A copying mistake is a mutation: it ends up in one new cell and its descendants. Rarely a chromosome fails to separate, leaving one cell with an extra and one short.
6. Aids: I P M A T (interphase is before mitosis). Count centromeres.
