Main question traced: *A resistant banana and a rhino rescue both use genetic techniques to stop something dying out. But does each one increase biodiversity, and how do you trace the effect?* Useful outcome: given an unseen crop or conservation case, the student can name a baseline, say which way each level (genetic, species, ecosystem) moves and why, and write a level-by-level conclusion (the route stop: "trace genetic, species or ecosystem effects").

## Strengths to keep

- **"Which level? Compared with what?"** is a compact, reconstructable anchor, set as the heading and earned by scenes 2 and 3 before it is named as an aid.
- **Scene 3's "same field, opposite answers"** makes the baseline idea visible in one comparison; it is the strongest teaching beat and directly targets the HSC marker-reported fault of generic claims.
- **The resistant Cavendish shows the site's key point exactly**: the technique protects the crop while its gene pool stays narrow, and the two baseline chips put "+1 gene" and "still one clone" side by side.
- **The rhino case is current and corrected**: the embryo route first, then the stem-cell route as the one that could widen the founder pool (correcting the site's "minimum diversity" framing).
- **Both attempts transfer.** 10a applies b08's gene flow to a new herbicide case at the genetic level; 10c asks for the whole route stop on an unseen restoration claim.
- **Scene 5 stays (project manager decision).** With each tag dimming as the next lands, it is within the clutter rule, and its herbicide sentence sets up 10a's context without giving the answer (10a asks about the wild population's genetic level, scene 5 about the field's species level).
