## Findings

**F1 (minor). Scene 12 narration.**
Quoted: "while dissolved carbon dioxide keeps leaving at the same rate."
Problem: the screen and the model answer say "unchanged at first", but the narration drops the qualifier. As the dissolved concentration falls, the leaving rate also falls.
Replacement: "while dissolved carbon dioxide keeps leaving at the same rate, at first."

**F2 (should fix). Scene 14 on-screen line 2.**
Quoted: "so each new strand has the same sequence as the strand it replaces"
Problem: no strand is replaced. A new strand has the same sequence as the template's original partner strand. "Replaces" could suggest that the old strand is removed (a conservative or dispersive picture), which contradicts line 1 and the semi-conservative model.
Replacement: "so each new strand has the same sequence as the template's old partner strand"

**F3 (minor). Model answer (b) wording.** Covered in the learning review, S1 ("So daughters matched..." becomes "Daughters matched..."). This is not a science error, but it is part of the same causal-word problem.
