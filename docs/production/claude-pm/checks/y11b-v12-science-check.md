## Pump mechanism, values and practice checks

Scene 3 is an unnamed schematic inward pump. Scene 5 introduces “a real pump ... the sodium-potassium pump”, which can be a different case. Reusing the painted carrier does not itself prove they are the same mechanism. Inward P-type transport is not biochemically impossible: [direct KdpFABC research](https://pmc.ncbi.nlm.nih.gov/articles/PMC7535926/) describes an ATP-dependent K⁺ uptake system with a phosphoenzyme intermediate. Thus no finding claims the generic inward illustration is intrinsically false. Clarify the case switch, or use root’s coherent Na-export scaffold option. The author note currently calling the generic mechanism the sodium-potassium pump must match that choice. If it becomes Na/K, phosphorylation is coupled to the outward Na leg and K return/dephosphorylation must not be reversed. Do not generalise covalent pump phosphorylation to all transport proteins.

The sodium-potassium ratio 3 Na⁺ out/2 K⁺ in per ATP is correct, giving net one positive charge outward. [Skou’s first-person Nobel lecture](https://web.as.uky.edu/Biology/faculty/cooper/ABLE-2021/ABLE-2021-MembranePotenial-tempAndK/Nobel%20prize%20Na-K%20pump.pdf) details the phosphoenzyme cycle and stoichiometry. Its maintaining ion gradients and contributing to animal-cell volume control are appropriate introductory reasons for paying energy. “Water follows salt” remains a net osmotic shorthand, not a literal rule that only sodium determines volume. The plant-nitrate example remains active uptake with indirect ATP support, as root accepted; the repair changes the misleading direct-cycle picture.

140/5 = 28, so “nearly thirty times” is sound. Typical mammalian Na⁺ inside 10–15 mmol/L versus outside 145 mmol/L is a reasonable example, not a universal cell value. A2 uses 145/12≈12.08 for Na⁺outside/inside and 5/1=5 for glucose. A1 ratios relative to 0.1 mmol/L outside are 400,600,800,760,720 at the five plotted points. The 0–60 min rise is 40 mmol/L,100 percent; the 60–120 min fall is 8 mmol/L,10 percent. The qualitative graph is explicitly illustrative, not an observed ATP measurement. Its 0.1 external reference needs a written value because it lies visually close to zero on the 0–100 axis; the card supplies it.
