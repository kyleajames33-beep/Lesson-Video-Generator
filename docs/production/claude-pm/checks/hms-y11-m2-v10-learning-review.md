## Findings

1. **Learning blocker, scene 4 says carbohydrate is "the only fuel the anaerobic systems can use".** One video earlier, v09 taught that the ATP-PCr system's fuel is phosphocreatine, and that cell is on screen in this video's table. A student who takes the sentence literally will write "ATP-PCr uses carbohydrate", losing the fuel-source criterion the syllabus names. The site's own line is narrower ("the only fuel usable anaerobically", in a table comparing fat with carbohydrate). Say: "Carbohydrate is faster, and it's the only food fuel that can be used without oxygen." The same wording problem reappears in v11's key note 1 (see that review). Students should keep PCr as a separate, non-food fuel.

2. **Note, "up to about eighty-five per cent" has no unit.** Scene 2 (and v11, v12, v13 and v14) use "per cent of maximum" for different maxima (effort, heart rate). Say "of maximum effort" here, and see the summary for the module-wide fix.

3. **Note, scene 7's EPOC list is long for listening.** Six uses of the extra oxygen in one sentence (PCr and ATP, lactate, haemoglobin, myoglobin, heart rate and breathing, temperature and hormones). The tail on the curve and the tags carry it; consider speaking the first four and letting the last two write silently.
