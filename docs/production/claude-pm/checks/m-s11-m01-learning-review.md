## Should fix

**SF1. Scene 6 and the memory aid state "profit is measured on the cost price" as an absolute rule.** The site lesson (`year11/managing-money/lesson03.sa.html`, line 377) says "Divide by the cost price ... unless the question explicitly asks for profit as a percentage of the selling price", and HSC-style questions do sometimes ask for it. A student who learns "always the cost price" will answer such a question wrongly. Fix: in scene 6 add one sentence after "measured on the cost price": "Unless a question asks for a percentage of the selling price, use the cost price." Add the same condition to key note 5 ("% profit or loss on the cost price, unless told otherwise"). The memory aid can stay as it is.

**SF2. The general multiplier "× (1 + r%)" is written before the student has seen r used as a percentage inside a sum.** A student weak in algebra may read "1 + r%" with r = 3 as 1 + 3 = 4. Scene 7 and key note 1 rely on it. Fix: on the memory card and key note 1, write the worked form beside it on first use, "Up 3%: × (1 + 0.03) = × 1.03", and say once in scene 7 "r per cent written as a decimal". This keeps the general rule and removes the misreading.
