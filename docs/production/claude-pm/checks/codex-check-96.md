## bio-m6-b18

1. **Attempt 2 model answer and scene 10d Visual: copying mature mRNA does not restrict cDNA to the coding sequence.** Old model text: "Copy 2 was made from processed mRNA (as complementary DNA), so its introns are already absent and it contains only the coding sequence." Corrected model text: "Copy 2 was made from processed mRNA, so the introns have already been removed and its protein-coding sequence can be translated correctly." Old visual row: "Copy 2: introns removed, coding sequence only, working protein". Corrected visual row: "Copy 2: introns removed, correct coding sequence, working protein". Mature mRNA includes untranslated regions, which can also be copied into cDNA. The correction preserves the reason the two copies behave differently. [NHGRI, cDNA synthesis](https://www.genome.gov/genetics-glossary/copy-DNA-cDNA); [Kozak, analysis of the untranslated regions of human cDNAs](https://pubmed.ncbi.nlm.nih.gov/11161792/).
