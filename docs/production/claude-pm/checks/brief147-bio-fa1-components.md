# Brief 147: shared Biology FA1 components

Completed 2 November 2026 after all twelve v07–v12 review reports. Component work only; no source design, full lesson, registry, audio, video or production plate was changed. Root owns the status entry and asset manifest.

`src/explainer/biology/fa1/index.ts` exports `SizeLadder`, `AssessBalance`, `GapBox`, their prop types and the scientific model helpers. Usage and limitations are in the folder's `README.md`. The existing house ink/paper/Biology colours and Inter Tight face are retained. The Remotion skill was read and applied: motion comes from frame-derived props, with no CSS or wall-clock animation.

- `SizeLadder` uses logarithmic positions from 100 µm to 0.1 nm. Each decade has equal spacing. The eye, ordinary light and best-instrument electron limits are 100 µm, 200 nm and 0.2 nm. The moving shaded zone changes logarithmically, and the cellular 1–2 nm note stays separate. Object labels show their measured size; optional painted thumbnails keep their native aspect ratio. The marker represents size, while the readable thumbnail is explicitly not drawn on one linear pixel scale with every other object.
- `AssessBalance` requires a criterion, accepts evidence chips for both sides and an authored judgement/tilt. Chip counts never calculate the angle. A seven-impact/three-limitation proof remains level when no tilt is requested, then tips only when an explicit judgement angle is passed. Long chip labels wrap; a pile that cannot fit is rejected rather than silently shrinking or truncating its contents.
- `GapBox` uses seeded independent random walks, reflected outer/divider encounters and a per-species pass rule. Counters record actual geometric crossings. Counts conserve each species, and current right-side count equals initial right count plus cumulative rightward minus leftward crossings. The recent equal-time window and its arrow remain distinct from cumulative transfer. Finite windows can reverse, exact 23/23 is not required and no equilibrium freeze is imposed. A request past the precomputed interval throws so the caller must provide enough simulated time. Prediction mode hides numerical counters and the arrow while motion continues.

Scientific checks: `node src/explainer/biology/fa1/verify.mjs` passes 174,628 assertions across log positions, units, seeded repeatability, crossing direction/aperture geometry, reflections, per-species conservation, blocked solute, recent-window event counts, continuing motion and finite-window reversals. These include exhaustive state checks, not 174,628 distinct scientific claims. A hypothetical 40/6 system observed at 23/23 necessarily has cumulative net transfer 17; the actual run is allowed to have other counts. Results: `work/brief147/components/scientific-checks.json`.

Targeted TypeScript check passes: `npx tsc -p src/explainer/biology/fa1/tsconfig.json`.

All text bounds fit. Identical scientific times at 30 and 60 fps produce identical SVG. Results and native text boxes are in `work/brief147/components/still-audit.json`. Native and phone stills were visually inspected for readable labels, aligned arms, separate total/recent counters, clear divider apertures and no clipping.

Root's product-copy review is applied: author/debug notes default off. The particle diagram uses crossings during an equal-time interval and plain overall-change labels; model-step units and provenance notes are opt-in. Crossings since the start are also opt-in. The balance's count-versus-judgement explanation is an optional teacher note. The ladder retains the scientific cellular-resolution note, and shows its thumbnail-scale note only when an image is present or author notes are requested. Static QA explicitly rejects those implementation strings in the default diagrams.

Limits: this is an illustrative tracer model, not molecular dynamics or a quantitative model of Visking permeability/osmotic pressure. The blocked-sugar setting does not claim real Visking tubing excludes sucrose. The scale shows resolution references, not a guarantee that every instrument/specimen reaches them. Static checks do not establish continuous playback, final lesson fit, human listening or teaching approval. Thumbnail crop QA and the independent painted-plate inspection are separate brief 147 work.
