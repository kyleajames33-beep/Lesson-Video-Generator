## Main question and the useful outcome

Main question (as stated): "An ethanol molecule has fewer electrons than butane, yet ethanol boils about eighty degrees higher and mixes with water. How does one OH group change an alcohol's properties, and how do we name and classify alcohols?"

Useful outcome: a student can name a single-OH alcohol up to C8 with methyl or ethyl branches, classify it by counting the carbons on the C–OH carbon, and explain (a) an alcohol against an alkane with the same electrons, (b) the trend along the primary series, (c) the C₄H₁₀O isomer order, and (d) why short alcohols mix with water and long ones form a layer, each with the intramolecular and intermolecular bonding named.

One main question: yes, with a seam. The hook is a properties puzzle, and naming and classification (scenes 3 to 6) are a detour before the puzzle is resolved in scenes 7 and 8. Scene 7's "Back to the boiling point puzzle" signals the return, and classification is needed for scene 10's isomer labels, so the detour earns its place. Keep as one video; no split recommended (the four syllabus actions share one molecule set and one boiling point strip).

## Findings

### S1. Should fix: the memory aid reads as "hydrogen bonding always beats size"

- Exact text (scene 13): "Hydrogen bonding wins, then **size**." Notes screen: "*Hydrogen bonding wins, then size.*"
- Student question: "c03 told me size wins between series. Now hydrogen bonding wins? So methanol (65 °C) should boil above octane (126 °C)?" The author's own assumption check says "wins" holds only for molecules of similar size, but the phrase does not carry that condition, and a mnemonic is remembered without its footnote.
- Replacement (scene 13): "Same size? Hydrogen bonding wins. Same family? Size wins." (+24 characters.) Handwritten line and notes-screen memory aid: "Same size? Hydrogen bonding wins. Same family? Size wins."
- Understanding enabled: the aid now states the controlled variable for each comparison, matches scenes 8 and 9 exactly, and agrees with c03's "size still wins" between hydrocarbon series.

### S2. Should fix: the running time is over the ceiling; fund S1 with trims

- The author's estimate is 573 s with holds; the ceiling is about 570 s. S1 adds 24 characters.
- T1, scene 12: delete "Long-chain alcohols mix better with non-polar solvents, like hexane." (−68). The author's own fallback; the solvent chip stays on screen silently and key note 4 keeps it. Move the chip's cue to "layer".
- T2, scene 5: delete "The class matters later, for reactions." (−39). The "reactions: later video" chip stays, cued on "primary".
- Net with S1, M3 and M5: about −75 characters (about 6,277), about 567 s with holds. Recount after editing. Do not cut scene 8.
