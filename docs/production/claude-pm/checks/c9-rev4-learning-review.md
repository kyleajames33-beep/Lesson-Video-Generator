Main question: if you change the temperature of a mixture at equilibrium, what happens to K, and how can you tell which way it goes? Entry knowledge traced from C1 to C8 as they now stand (C5 and C8 no longer teach rate constants).

## Findings and resolutions

### BLOCKER

1. **Scene 2 contradicted C3.** "Temperature is different: it changes how fast each reaction runs" implies that adding a chemical does not change a rate, but C3 taught that adding Fe3+ speeds up the joining rate at once. A student asks: "adding a reactant also changed a rate, so why did K not change then?" Repair applied: a disturbance changes the amounts, so particles meet more or less often and one reaction runs faster for a while; the mixture shifts until products over reactants is the same number again, with different amounts; each collision is just as likely to work as before, so the same K; heating makes collisions more likely to work at the same amounts. Enables: the difference between "more meetings" (amounts) and "more successful meetings" (temperature). Resolved.
2. **Scene 5b visual showed the wrong direction.** It said the N2O4 count rises while NO2 falls, but in 2NO2 ⇌ N2O4 heating speeds up the reverse (splitting) reaction more, so N2O4 falls. Students would see the tube contradict the narration. Repair applied: N2O4 dots fall and NO2 rise; the narration adds "It is the same tube going brown; only the way we write it has changed" and names N2O4 as the product now. Enables: one physical change, two ways of writing it. Resolved.
