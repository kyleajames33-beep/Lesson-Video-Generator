## Memory aids

- "Substitutions: Silent, Missense, Nonsense", "Multiples of three don't shift the frame", "Non-disjunction: chromosomes fail to dis-join" and "Somatic stays with you" are recalled, not re-taught, each where it decides a step.
- "Align base by base, then read in threes." (new) Useful and accurate, but it tells the student what to do and not when to do it (should fix 1). With the trigger "several codons in a row differ" it becomes a rule a student can apply to a new case.
