## Student learning trace (entry knowledge: B1, B2b, B3a, B3a2)

- The reproduction knowledge each method needs is shown on screen before it is used (timing and ovulation for insemination, flower parts and pollen tube for pollination), with the exception that the flower labels appear one scene late (SHOULD FIX 1 and 2).

- Evaluate is taught by use: criteria defined, four rows ringed on the words, a three-part answer, and a model whose structure is built card by card. The weakness is that the verdict is on screen before the weighing (SHOULD FIX 4).
