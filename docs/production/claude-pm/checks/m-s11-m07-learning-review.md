## Should fix

**SF1. Scene 4 draws the wrong conclusion from cost per day.** It compares $4.04 a day with last year's $4.48 a day and says "So the house is using a bit less than last year." Scene 3 has just said that rates "change each year", so a lower cost per day could come from a cheaper rate with the same or higher use. This teaches a student to read cost as usage. Fix: say "So this bill costs a bit less per day than last year. To check the house is really using less, compare kilowatt-hours per day, which most bills print." Optionally show "812 ÷ 91 ≈ 8.9 kWh a day" beside the cost per day. The memory aid's "Check: cost ÷ days, same season last year" can stay.
