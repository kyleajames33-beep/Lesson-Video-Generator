## Student learning trace (entry knowledge: B1 chromosomes and DNA, B3a cell division in a zygote, B4 DNA copying)

- Main question (hook): "How does a cell divide so that both new cells keep every chromosome, an exact copy of the parent's?" The learner outcome is to explain mitosis in terms of chromosome counts and to predict the chromosome and chromatid number at each stage.
- Vocabulary is built before it is used: chromosome (one DNA molecule wound with protein), set (one of each kind), homologous pair, diploid and haploid, chromatid, centromere. The earlier review's blockers (the word "set" meaning two things; "one of each pair to each end") are resolved on screen: "both sets again" for the new cell and "each chromosome on its own, not paired up" in metaphase.
- The causal chain is complete and drawn: a chromosome cannot be cut in half (two grey halves with crosses), so the cell copies first (interphase, S phase), each copy stays joined at the centromere (sister chromatids), mitosis shares the copies out (fibres pull one chromatid of each chromosome to each pole), so each new cell gets a copy of every chromosome. The "why identical" scene restates it with the same cell.
- The counting traps (chromosomes versus chromatids, "doubled and then halved") are taught on the same four-chromosome model cell, then the human numbers, then two fresh attempts, and each wrong answer has a stated cause in the feedback. This is the lesson's strongest part.
- The attempt is a bounded two-part transfer (different organism, a different stage picture) with every condition visible and a 10 s countdown; Q2 can be answered by someone who has followed the metaphase scene.
- Honest scope: mistakes (mutation, extra or missing chromosome) are named as rare; "Next: meiosis" sets up the one-set idea. No meiosis content is taught early.
