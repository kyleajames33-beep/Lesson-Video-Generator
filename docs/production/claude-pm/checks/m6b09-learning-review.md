Main question traced: *Bread, fine wool and human insulin all come from biotechnology, but only one needed DNA changed in a lab. So what counts as biotechnology, and what does each kind actually change?* Useful outcome: given any named biotechnology, the student can say whether it uses an organism's process, chooses the parents, copies existing DNA or changes the DNA itself, state that kind's advantage, and avoid assuming that every biotechnology edits DNA (the route stop).

## Strengths to keep

- **One question turns a definition list into a decision.** "What does it change?" is asked in the hook, built lane by lane on one board, practised in 10a and closed as the decision rule. It is exactly the route stop.
- **Causes before names.** The bubbles drift into the crumb before "fermentation"; the flock's bar rises before "selective breeding"; DNA slides into the plasmid before "recombinant DNA".
- **The DNA strip under every lane is the video's advantage.** A student can compare an unchanged strip, reshuffled rings, a duplicated strip and an amber insert at a glance; this is the contrast the stop asks for.
- **Selective breeding is taught as a population change, not a DNA change.** "Each lamb still got a normal mix of its parents' alleles. But by choosing the parents, breeders changed which alleles were passed on" corrects the site's own error (site correction 6) and links to b08's allele frequency.
- **Attempts are genuine transfer.** 10a's four new cases (yoghurt, one bull's semen, banana suckers, Bt cotton) test the four-way frame, and 10c's compare item makes the same criteria appear on both sides.
