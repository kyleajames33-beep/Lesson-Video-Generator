## Findings

A student will try to map one list onto the other and fail. Either rewrite the hook's three chips as previews of the later stations ("meaning or fact?" for method, "who did you ask?" for sample, "safe to read aloud?" for ethics) and light each chip again when its station fills, or replace them with scene 2's four tests. Students should see the hook as a trailer for the cycle, not a competing checklist.

2. **Should fix, 10a repeats scene 7's reliability example.** Scene 7 teaches reliability with "If interviewers word questions differently, answers move for the wrong reasons"; 10a is three interviewers wording questions differently. Use an unseen reliability case, for example: "A class runs the same health-meanings survey twice, once in the week after exams and once in a normal week, and gets very different results." Feedback: reliability, because conditions changed between runs, not the people; repair, run both at comparable times with the same instructions; crossed mistake "validity" (the questions still ask the right thing). Or test credibility, which scene 7 gives only one sentence: "A report on teenagers' energy levels is published by an energy-drink company."
