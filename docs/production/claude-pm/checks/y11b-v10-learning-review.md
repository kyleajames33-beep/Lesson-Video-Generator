## Learner trace

Main question: how can a visible or measured change provide evidence for diffusion and osmosis? Entry is v09's particle causes and Stage 5 fair testing. Visking tubing, sucrose, a control and percentage mass change are introduced beside their apparatus or worked calculation. A learner should be able to describe a defensible setup, identify a measured outcome and explain what the result does and does not establish.

The Set up / Measure / Means frame is a useful reusable method. Keeping the apparatus visible while introducing a new measure prevents the student from having to remember an absent bag or ruler. Both-direction water movement is shown rather than replacing it with a single one-way flow.
