- **Types 1 and 2 (reused).** Unchanged teaching. In the split they come straight after the hook, so the type 1 "divide first" and the type 2 "E row first" are the first two things learnt. Fine.
- **Type 4 (reused).** The original visual flashed the bracket between cards 3 and 4 ("same givens, different demand"), which refers to a type not yet taught in this video. Changed to a card 4 flash only. The bracket idea moves to G03b's hook.
- **Attempt (new).** "Same concentrations as the first vessel, at the ICE table temperature, which way?" A student must notice that this is a direction question, so the ratio is Q, then compare with 229. The arithmetic is already done (53.3), so the pause tests the decision, which is the main question. Every given is on the card, including K and the concentrations with units. Nothing answer-bearing during the hold (no 53.3 on screen).

- **Decision board and key notes.** Three types only; the notes are a small, copyable set; the key notes add the one new idea (only an equilibrium mixture gives K).
- **Handoff.** "Next: K and a start, and an amount added." Matches G03b.
