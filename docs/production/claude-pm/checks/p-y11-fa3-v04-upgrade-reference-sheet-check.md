# Brief 242: Physics FA3 v04 reference sheet

13 November 2026. 0 blockers; 1 should-fix under root decision 9.

The official 2025-syllabus data and formulae sheet, page 3, prints the point-charge field as E = [1/(4 pi epsilon_0)] q/r squared. It prints Coulomb force in the same permittivity form. It does not also print the k form on that formula page. This is the 2025 syllabus sample material, rather than a 2025 examination from the old syllabus. The page was rendered and visually inspected.

Current v04 says both forms stay on screen while the check is open. Root decision 9 therefore now requires the screen treatment to be aligned. This is a compliance finding; both forms are mathematically equivalent. No source or narration edit made.
