## Findings

No blockers.

### S1. Should fix: scene 3 does not say why evaporation cools the liquid left behind

- Exact text: "Here's the trick. The molecules that escape take energy with them, so the liquid left behind **cools**. The faster it evaporates, the bigger the temperature drop."
- Student question: "If some molecules leave, why does that make the rest colder? Temperature is about how fast they move."
- Problem: this is the cause the whole method rests on, and it links to Year 11 (temperature as average kinetic energy). Without "the fastest ones escape", scene 8's "Fewer molecules have enough energy to break free" has no earlier anchor.
- Replacement: "Here's the trick. Only the fastest molecules have enough energy to escape, so the ones left behind are slower on average, and the liquid **cools**. The faster it evaporates, the bigger the temperature drop." The visual already slows the remaining molecules; make the escaping molecule visibly the fastest jiggler before it leaves. Tag: "fastest escape → the rest are slower → cooler".
- Understanding enabled: the student can explain why ΔT measures evaporation, and scene 8's chain (stronger forces → fewer escape → smaller drop) becomes reconstructable.

### S2. Should fix: scene 11's accuracy card repeats scene 10 and gives a weak exam answer

- Exact text: "**Accuracy**: there's no accepted value for a temperature drop, so check the **ranking** against the published boiling points instead." Card: "Accuracy: close to the true value? No accepted ΔT, so check the ranking against data-book boiling points: it matches."
- Student question: "So accuracy just means the order is right? Isn't that what scene 10 said?"
- Problem: agreement of the ranking with independent data supports the validity of the conclusion; it does not show that the measured values are close to true values. Students who write "accurate because the ranking matches" in an HSC evaluation may lose the mark.
- Replacement narration: "**Accuracy** depends on the probe reading true temperatures, so check it against a calibrated thermometer. There's no accepted value for a drop, but the **ranking** matches the published boiling points, which supports the conclusion." Card: "Accuracy: probe checked against a calibrated thermometer. No accepted ΔT; the ranking matches the data book." Key note 5: "accuracy: check the probe against a calibrated thermometer; the ranking matches data-book values."
- Understanding enabled: the student separates "are my readings true?" (accuracy) from "does my conclusion hold?" (validity, supported by agreement), which is the distinction HSC evaluation questions test.

### S3. Should fix: an unexplained hazard code on screen (scene 13)

- Exact text (risk table): "vapour (H336; hexane also H373, H361f)" / "drowsiness; nerve damage with repeated exposure (hexane)".
- Student question: "What's H361f?"
- Problem: a code with no meaning is reading load with no learning, and the science check finds the hexane STOT RE entry has changed (H372 from 1 May 2026 in the EU). Resolve with the science check's S1: either replace hexane in the practical (recommended there), or give every code on screen a plain harm ("suspected of damaging fertility").
