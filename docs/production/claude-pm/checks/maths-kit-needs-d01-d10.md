## Missing from the named list

- A paired function/derivative graph tracer with radian ticks and independently labelled y and gradient scales (d05, d09). The general graph kit should expose this rather than fake it with a painted curve.
- Nested inner/outer expression slots and derivative-factor highlights (d01-d04 recall, d06), plus a two-contribution product cue (d07).
- Domain-aware endpoint/corner/hole/asymptote markers and separate included versus excluded interval endpoints (d03-d04,d06,d08-d10). A sign chart must not bridge a domain gap.
- A candidate/value comparison table with exact fractions and retained function/domain givens (d10). Distinguish an attained extremum from an unattained endpoint limit for later open-domain work.
- Bracket-aware large fractions and cancellation marks that never delete the original domain exclusions (d08).
- Shared stable question card, 10-second countdown, brief feedback and key-notes hold. Reuse existing shared components if their real appearance fits; these are needed across all ten.

No new painted plate is required for this opener. Finance timelines and probability densities remain later strands. The existing fixed square graph cannot represent all these functions; graph domains and discontinuities need genuine function plotting. Keep one coordinate transform for curve, tangent, points and slope markers. These requirements do not authorize narration or rendering.
