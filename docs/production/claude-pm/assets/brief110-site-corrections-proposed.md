## Notes excluded from the confirmed-error rows

- L12 “reflux for carboxylic acid or ketone” describes an acceptable ketone preparation but can imply reflux is required. Optional clarification: secondary alcohol gives a ketone whether it is distilled or refluxed. Not logged as a false condition.
- L15 pentyl propanoate “pear”: no decisive primary flavour source was obtained, so the author's proposed odour correction is not confirmed.
- L15 Q8 washing losses: not an incorrect answer and not a correction.
- L17 350 mg/L Ca²⁺ is about 874 mg/L as CaCO₃. It is very high but possible. Replacing it with 350 mg/L as CaCO₃ changes the data, so it is not an automatic reporting correction.
