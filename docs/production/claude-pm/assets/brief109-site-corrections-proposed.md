## Clarification notes, not additional confirmed errors

- L21 exact text: “Thermosets cannot be recycled by melting. Primarily relevant in condensation polymer context (Lesson 22).” Suggest removing the second sentence: crosslinking determines thermoset behaviour, and vulcanised addition-polymer rubber is a counterexample. The page is making a scope comment, so do not label the entire first sentence false. [RSC rubber crosslink research](https://experts.mcmaster.ca/scholarly-works/1689169).
- L22 exact heading: “Identifying Linkage Type at a Glance:” followed by “Ester linkage” and “→ polyester”. Add “along the backbone” so pendant ester groups such as PMMA's are not mistaken for polyester links. The page does not explicitly claim that every ester-bearing polymer is a polyester.
- Biology L16 lacks the disc-diffusion practical described by P05. This is a coverage note, not a false factual quotation. Add a teacher-reviewed interpretation resource if desired; this hand-in does not supply a growth protocol.
- Biology L05 temperature issue and Chemistry L22 intrachain-amide melting explanation are already logged. No duplicate proposed. Root is reconciling the official NSW resource's inclusive narration and strict screen symbol in the existing safety entry.
