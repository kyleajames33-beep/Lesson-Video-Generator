- **Learner question kept (route).** "Why does a reciprocal primitive need an absolute-value log?" The answer, built in order: the power rule needs division by n + 1, which is zero at n = −1 (hook); we need a curve whose gradient equals the height of 1/x; ln x does this for x > 0 only (2); for x < 0, 1/x is negative, and the mirror of ln x in the y-axis, ln(−x), has exactly those gradients, because mirroring reverses every slope (3); both pieces are ln|x| (4); the gap at 0 separates them, so each has its own constant, and in practice one works on one piece (5).

## Teaching checks

- **Does it explain causes?** Why the power rule fails: it divides by n + 1 = 0 (1). Why ln x is a primitive for x > 0: its gradient equals the height of 1/x, matched at x = 2 (2). Why the negative side needs ln(−x): 1/x is negative there, and the mirror reverses every slope at matching points, matched at x = −2 and confirmed by the chain rule (3). Why the bars: both pieces are ln|x|, and its gradients trace 1/x on both sides (4). Why a constant on each piece: sliding a piece keeps its gradients, and nothing joins the pieces across 0 (5).
