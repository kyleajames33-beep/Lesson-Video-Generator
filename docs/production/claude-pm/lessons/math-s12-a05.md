### 2. add the same, or multiply by the same
> Put the two videos side by side in tables. For the steady video, each day adds one thousand views. The difference between one day and the next is always the same. That's a linear relationship, the kind that makes a straight **line**. For the doubling video, the differences keep growing, a hundred, then two hundred, then four hundred. But divide each number by the one before it, and you always get **two**. That's called the ratio, and here it's the same every time. Each day multiplies by the same number. That's an exponential relationship. So here's the test for a table. Same difference each step, it's linear. Same ratio each step, it's **exponential**.

### 4. one relationship, four ways
> The simplest exponential is y equals two to the x. Two to the x means two, multiplied by itself x times. We can show it four ways. The equation, y equals two to the x. A table, where x equals one, two and three give two, four and eight. A set of ordered pairs, which is the table written as a list, one, two, then two, four, then three, **eight**. ### 5. drawing y = 2^x
> Now draw it by hand. Plot the points from x equals minus two up to three, and join them with a smooth curve, not straight lines, and not a **ruler**. Then read off its features. It crosses the y-axis at one, because two to the zero is one. As x goes left, the values halve, a half, a quarter, an eighth, getting closer and closer to the x-axis, but never reaching **it**. Halving never gets you to zero. So the curve never touches or crosses the x-axis. And as x goes right, it rises faster and faster. That's exponential **growth**.

### 6. y = 2^(−x): the mirror
> Now y equals two to the minus x. Make a table. At x equals one, it's two to the minus one, a **half**. At x equals minus one, it's two to the one, which is **two**. Every value from two to the x turns up again, on the other side of the y-axis. The point minus one, two on this graph matches one, two on the old one. So y equals two to the minus x is the mirror image of y equals two to the x, flipped in the y-**axis**. It still crosses at one, and it still never touches the x-axis.
