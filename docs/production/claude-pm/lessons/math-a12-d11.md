- **Learner question kept (route).** "Why does differentiating tan x give sec squared x?" The answer, built in order: the slope of y = tan x is never less than 1 and grows towards each asymptote; measured, each slope is one more than the height squared (2); because tan x = sin x/cos x, the quotient rule splits the slope into the top's turn, cos x/cos x = 1 everywhere, and the bottom's turn, sin²x/cos²x = tan²x (3); combined over cos²x, the top is cos²x + sin²x = 1, so the derivative is 1/cos²x, which is sec²x (4).

- **The hook surprise (graph driven).** A moving tangent rides the middle branch of y = tan x from x ≈ −1.2 to 1.2: steep, easing to its flattest at x = 0 (slope 1), then steep again. It never gets flatter than slope 1, and it never falls. Students know a curve's slope can be 0 or negative; tan's never is. The question: why is the slope never below one, and what is it exactly?
- **Measure, then notice (scene 2).** Three held points with `ReadoutPanel` rows (height, gradient): x = 0 (0, 1), x = π/4 (1, 2), x = π/3 (√3 ≈ 1.732, 4). - **Cause: the two turns (scene 3; d08 recalled in one sentence).** d08 split a quotient's slope into the top's turn, f′/g, and the bottom's turn, −fg′/g². For sin x/cos x: the top's turn is cos x/cos x = 1 at every x in the domain, which is where the 1 comes from; the bottom's turn is −sin x × (−sin x)/cos²x = sin²x/cos²x = tan²x, the height squared. Readout rows at π/4 (1.000, 1.000, gradient 2.000) and π/3 (1.000, 3.000, gradient 4.000). Spoken scope: "between zero and pi over two, cos x is shrinking, and a shrinking bottom makes a positive fraction grow, so this turn adds" (true there; the algebra holds wherever cos x ≠ 0, author note a). Near π/2, cos x → 0, so tan²x grows without limit: the steep wall.
- **The proof (scene 4; `cid8c675e3` "show that").** `AlignedAlgebra`, one row per spoken step: d/dx(tan x) = d/dx(sin x/cos x), cos x ≠ 0; = (cos x × cos x − sin x × (−sin x))/cos²x; = (cos²x + sin²x)/cos²x; = 1/cos²x (grey tag "sin²x + cos²x = 1"); = sec²x, where sec x = 1/cos x. A grey side row splits the third line into cos²x/cos²x + sin²x/cos²x = 1 + tan²x, tying it to scenes 2 and 3. Then sec²x ≥ 1 because 0 < cos²x ≤ 1: the slope is never below one. The site's derivation (card 06) is the same; its "always increasing on its domain" is not used (site log item 14).

### 3. the two turns: why the slope is one plus tan squared

And near pi over two, cos x gets close to zero, so the bottom's turn grows without any limit. That's the steep **wall**.

### 4. the proof
> The syllabus asks you to show this result, so here's the proof, line by line. Tan x is sine x over cos x, and cos x can't be **zero**. The quotient rule gives cos x times cos x, minus sine x times minus sine x, all over cos squared x. The two minus signs make a plus, so the top is cos squared x plus sine squared **x**. By the Pythagorean identity, that top is **one**. So the derivative is one over cos squared x. One over cos x has its own name, sec x. So the derivative of tan x is sec squared **x**. And cos squared x is never more than one, so sec squared x is never less than one. That's why the slope never drops below **one**.
