### 2. drawing a vector to scale
> First, a vector diagram needs a **scale**. That's how much real quantity each centimetre of arrow stands for. Say one centimetre stands for one metre per second. A velocity of four metres per second east is an arrow four centimetres **long**, pointing east. The tail is where it starts. The tip shows the direction. The same recipe works for any vector. A displacement of four metres, an acceleration of four metres per second **squared**: same arrow, different label and scale.

Visual: board clears to a squared-paper strip with the compass. On "scale" a coded scale bar writes at the bottom left: "scale: 1 cm = 1 m s⁻¹" with a 1 cm tick bracket. ### 3. why tip to tail: one move after another
> Now, why do we join vectors tip to tail? Think about displacements. A drone flies four metres east, then three metres north. The second move can only start where the first one **ended**. Drawing both arrows from the start would mean two separate trips from the start, and that isn't what happened. So we slide the second arrow until its tail sits on the first arrow's tip. The arrow keeps its length and its direction. It just moves. Then the result is one arrow from the very first tail to the very last **tip**. That's the **resultant**: the single vector with the same effect as both together. It's the trip you'd make if you flew straight there.

### 4. velocities add the same way, second by second
> Velocities add tip to tail too, and the river shows why. In each second, the boat's own motion carries it three metres **across**. In that same second, the water carries it four metres **downstream**. The boat's motion through the water hasn't changed. The water itself is moving. Both happen, so those two moves join tip to tail, and the boat ends up five metres along the **slant**. Next second, the same again, and again. So the boat's actual velocity is five metres per second, along that slant. That's why it lands downstream.

### 5. worked example: the boat's resultant velocity

If the arrows weren't at right angles, you'd measure the resultant with a ruler and protractor instead.

### 6. along one line, and in any order
> When both arrows point the same way, the sizes simply add. Point the boat **downstream**, and it goes three plus four, seven metres per second. Point it **upstream**, and the arrows face opposite ways. The water wins by one, so the boat drifts downstream at one metre per second. So adding the sizes only works when the arrows line up. And the order never matters. Add the current first, then the boat's motion, and you get exactly the same **resultant**.

### 8. subtract by flipping: the change in velocity
> It's more than twenty. The change in velocity is final minus initial. It's the arrow you'd have to add to the first velocity to get the second. And subtracting a vector means adding its reverse. So flip the east arrow, to point **west**, same length. Then join it tip to tail with the north arrow. The change is about twenty-eight metres per second, toward the north-**west**. Check it: start with the east arrow, add this change, and you land exactly on the north arrow. That's bigger than either velocity. Subtracting a vector doesn't make it smaller. And during the turn, the car's acceleration, on average, points the same way as this **change**.

### 15. key notes (quiet, hold about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

1. A vector diagram uses arrows drawn to a stated scale: length shows magnitude, the tip shows direction. Displacement, velocity and acceleration are all drawn this way.
2. To add vectors, join them tip to tail. The resultant (the single vector with the same effect) runs from the first tail to the last tip. Order doesn't matter.
3. Perpendicular vectors: R = √(A² + B²), θ = tan⁻¹(B/A); state the angle's reference. Along one line, sizes add (same way) or subtract (opposite ways).
4. To subtract, reverse and add: A − B = A + (−B). Change in velocity Δv = v_final − v_initial; the average acceleration points along Δv.

## Teaching checks

- **Does it explain causes?** Why tip to tail: the second displacement starts where the first ended (3). Why velocities add the same way: in each second both displacements happen, and they chain (4). Why the boat lands downstream: its actual velocity is the slanted resultant (1, 4). Why Pythagoras applies: the chain makes a right triangle (5). Why magnitudes add only along one line (6). Why subtraction is flipping and adding: the change is the arrow you add to the first to get the second (8).
