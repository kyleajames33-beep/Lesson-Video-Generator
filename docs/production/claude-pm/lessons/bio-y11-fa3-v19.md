> Superposition works within one cliff. But how do you match cliffs hundreds of kilometres apart? Use index fossils. If two distant layers hold the same index fossil, they formed at about the same time. So their layers can be matched, and their orders joined into one longer sequence.

### 11. what relative dating can't do
> Now the limit. Relative dating gives order, not age. It can show this layer is older than that one, but not by how much. A centimetre of rock might hold a single year, or a hundred thousand, because sediment builds up at different speeds. So relative dating alone can't measure how fast evolution happened, which is exactly what the two tempo models argue about. For actual numbers, scientists use radioactive dating, which measures how much of an unstable element in the rock has broken down.

### 14. key notes (quiet, about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

- Relative dating: putting rocks and fossils in age order without numbers. Numerical (absolute) dating gives years, using radioactive decay.
- Superposition: sediment settles from above, so in undisturbed sedimentary layers, lower = older. A fossil deposited with its layer (not washed in from older rock) has the age of its layer, so reading up a sequence shows the order life forms appeared and changed.
- Conditions: folding can overturn layers and faults offset them, so check which way was up first. Erosion can remove layers (an unconformity: missing time).
- Cross-cutting: a dyke or fault is younger than the layers it cuts.
- Index fossils (widespread, easy to recognise, short-lived) match same-age layers far apart. Fossils occur in the same order worldwide. Relative dating gives order, not age or rate.

Memory: deeper is older, but only if nobody has turned the rock over.
