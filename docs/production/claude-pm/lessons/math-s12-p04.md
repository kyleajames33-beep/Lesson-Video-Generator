## Memory aid check

- **"Follow a path: multiply. Join paths: add."** with key line **"Branches from one point add to 1, and so do all the tips."** Original wording (Advanced s06 uses a different card). Meaning, as said in scene 8: a path is one stage after another, so its probability is the product of its branch probabilities; an event made of several paths is any one of them happening, so their probabilities add. Assumptions checked: each branch's probability is the chance at that stage given the path so far (said for without replacement as "the second branches already allow for what happened first"; for everyday events, multiplying the plain chances assumes one doesn't affect the other, said in 6 and A1); paths add because two different paths can't both happen. It helps a new case: a canteen that runs out of pies 0.1 of days and out of wraps 0.2 of days (assumed not to affect each other): both run out 0.02.
- **Considered, not used:** "AND means times, OR means plus" (true here only for separate paths and separate stages; it misleads for "or" with an overlap, p07).
