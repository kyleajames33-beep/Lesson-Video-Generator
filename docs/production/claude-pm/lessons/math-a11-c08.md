### 2. the tangent: point from f, gradient from f′
> Put the ramp on a grid, so its shape is y equals x squared, and the end of the track is at x equals two. A line needs two things, a point and a gradient. The point comes from f. f of two is four, so the point is two, **four**. The gradient comes from f prime. f prime of x is two x, so at two, the gradient is **four**. Now use the point-gradient form from earlier, y minus y one equals m, times x minus x one. That's y minus four equals four, times x minus two. Expand and tidy, and the tangent is y equals four x minus **four**. Check it. Put x equals two into the tangent, and you get four, so it does pass through the point. Leaving m as two x is the slip. The tangent is a straight line, so its gradient is a number, four, not a formula.

### 3. the normal: flip and change the sign
> The normal is the line through the same point, at right angles to the tangent. Think of a support strut fixed square to the track, right at its end. Perpendicular gradients multiply to minus one, so the normal's gradient is the negative reciprocal of four, which is minus a **quarter**. Flip the four, and change the sign. So the normal falls one unit for every four across. Here's why. Turning a line through a right angle swaps its rise and run, and one of them changes direction. Then y minus four equals minus a quarter, times x minus two. That's y equals minus x on four, plus four and a **half**. Multiply through by four, and you get x plus four y minus eighteen equals zero.

### 4. worked example: a cubic
> Let's try a cubic. Find the tangent and normal to y equals x cubed minus two x, at x equals two. The point: two cubed minus four is four, so it's two, **four**. The gradient: d y by d x is three x squared minus two, which is ten at x equals **two**. The height is four again, but the gradient is different, because the curve is different. The tangent is y minus four equals ten, times x minus two, so y equals ten x minus **sixteen**. The normal has gradient minus a tenth, so y minus four equals minus a tenth, times x minus two. That's y equals minus x on ten, plus four point **two**. Using minus ten for the normal is the slip. Flip the fraction, as well as changing the **sign**.

### 6. a flat tangent and a vertical normal
> One special case. At the bottom of the track, where x is zero, the tangent is flat. It's the line y equals **zero**. Its gradient is zero, and minus one over zero isn't a number. So the normal has no gradient. It's the vertical line x equals **zero**. You'll see this at the top or bottom of any curve, wherever it's flat. Writing a gradient for that normal is a common mistake. Whenever the tangent at x equals a is horizontal, the normal is just the vertical line x equals a.

### 7. a tangent can meet the curve again
> And one myth to clear up. A tangent doesn't have to touch the curve only once. The tangent to y equals x cubed at one, one is y equals three x minus two. Follow it to the left, and it meets the curve again at minus two, minus **eight**. Near the point of contact, it matches the curve's steepness. Far away, it's free to cross the curve. So a tangent is about matching steepness, not about touching once. That's why we defined the derivative using steepness.

## Practice questions and model answers

**Attempt 1 (scene 9; pack question 1, original, HSC style, 3 marks suggested, not an official marking scheme).** "Find the equations of the tangent and the normal to y = x² − 3x + 1 at the point where x = 3."
Model answer: f(3) = 1, so (3, 1). dy/dx = 2x − 3 = 3. Tangent: y − 1 = 3(x − 3), y = 3x − 8. Normal gradient −⅓: y − 1 = −⅓(x − 3), y = −x/3 + 2 (or x + 3y − 6 = 0). Classic mistake (crossed): "point (3, 3)".

**Attempt 2 (scene 11; original, HSC style, 3 marks suggested).** "Find the equation of the normal to y = x² at the point (1, 1). Find the other point where the normal meets the curve."
Model answer: dy/dx = 2x = 2 at x = 1, so the normal's gradient is −½: y − 1 = −½(x − 1), y = −x/2 + 3/2. Solving x² = −x/2 + 3/2: 2x² + x − 3 = 0, (2x + 3)(x − 1) = 0, so x = −3/2 (x = 1 is the given point). The other point is (−3/2, 9/4). Classic mistake (crossed): "normal gradient −2".

## Memory aid check
