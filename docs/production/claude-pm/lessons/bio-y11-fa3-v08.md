### 11. how to write a validity discussion
> The simulation, because it can run the same settings many times and show the spread. So to discuss validity, name the claim first. Say what the model represents, give a strength and a limitation, and for each limitation, say what it does to that claim. Then judge, and suggest an improvement for a limitation you named, like pairing the dots with the beads.

### 14. key notes (quiet, about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

- Validity: how well a model represents the real process. A right result doesn't prove a model is valid.
- Dots (predation) model. Strengths: shows variation, a pressure, differential survival, inheritance and population change, all visible. Limitations: no mutation; doubling, not mating or genes; a predator who knows the aim; fixed habitat; small numbers.
- Bead model: beads = alleles, bag = gene pool. Strength: tracks allele frequency. Limitation: the pressure is a rule you impose, so it can't show why a variant is favoured.
- Simulation: long runs, large numbers, mutation, migration, chance, different results between runs. Limitation: you see only the output.
- To discuss validity: name the claim; what the model represents; strength; limitation and its effect on the claim; judge and improve.

Memory: A model is a map: ask what it's a map of. Right answer, wrong reasons: a model can pass and still lie.
