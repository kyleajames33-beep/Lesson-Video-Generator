### 3. how fast? (worked doubling example)
> Now, how fast? In warm conditions with plenty of food, some bacteria can divide as often as every 20 minutes. Follow one cell. After 20 minutes there are two. Each of those splits in the next 20 minutes, so there are four, then eight, then sixteen. Every time, all the cells split, so the whole crowd doubles. So how many cells after 3 hours? Three hours is 180 minutes. Each doubling takes 20 minutes, so we count how many 20-minute steps fit into 180 minutes. 180 divided by 20 is 9, so that's nine doublings. Keep going for 10 hours and that's thirty doublings, about a billion cells, but only if the food never runs out. In real milk, the acid and other waste build up, so growth slows and stops.

### 11. key notes (quiet)
- Binary fission: a cell copies its DNA, the copies move apart, and the cell splits into two. It is asexual, so the new cells are clones of the parent, apart from rare copying errors. Bacteria, amoebae and paramecia reproduce this way.
- Budding: a new cell grows from the parent and breaks away. In baker's yeast the DNA is copied first and one copy moves into the bud. Baker's yeast usually reproduces this way, and so do a few protists such as Acineta.
- Copy, share, split. The DNA must be copied before the cell splits, or one new cell would have none and no instructions.
- Under good conditions some bacteria divide every 20 minutes. Starting from one cell, the number after n doublings is 2 to the power n. Running out of food, or a build-up of waste, slows or stops this.
- Conjugation passes DNA from one existing bacterium to another. It changes cells that already exist, but makes no new cell, so it is not reproduction.
- Memory aid (large): Copy, share, split.

## Memory aid and assumptions

Aid: **"Copy, share, split"** (written for this lesson) with the bank's trap **"Binary fission makes more bacteria. Conjugation makes different bacteria"** (`module5-memory-aids-2026-10-11.md`, Module 5 reproduction and continuity section), reworded to **"Fission makes more cells. Conjugation changes cells that already exist."**, plus the line "conjugation copies and shares DNA too, but it never splits, so it makes no new cell".
Assumptions checked:
- "Copy, share, split": the steps are in the right order for bacterial fission, yeast budding, amoeba and paramecium fission. For a bud, "split" means the bud breaks away. For the budding protist (Acineta) "split" means the bud is released. The narration does not say Acineta copies its DNA first, so for it the aid's first step is asserted, not shown (a Codex fact check item; the Claude science check could not find the suctorian nuclear steps for Acineta, so no narration or note claims them). The aid does not describe the nuclear stages (mitosis) for yeast and protists, which are for b05a, and it is not applied to spores, mould or any sexual method.
- On its own the aid breaks on the conjugation trap, because conjugation also copies and shares DNA. The line "it never splits, so it makes no new cell" repairs this and is shown with "3 split" greyed beside the conjugation drawing.
- "Fission makes more cells. Conjugation changes cells that already exist": true for the bacterial conjugation described (the number of cells does not change and the recipient cell receives a copy of some DNA). It does not claim conjugation is the only source of difference. Mutation, covered in the first video, also gives differences.
- The bank's "Binary fission makes more bacteria" wording keeps "bacteria" while this lesson uses "cells" because the aid also covers the protists. "Cells" is used in the notes and the final scene, and the milk hook keeps "bacteria".
- The sequence is not offered as a rule for all single-celled reproduction: many protists have other life cycles (author note below), and the learner copy names only the examples that fit.
