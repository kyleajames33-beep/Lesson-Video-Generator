## Decisions

- **Main question:** *When a question asks you to calculate K, how do you tell which type it is, and how do you fill an ICE table from a start and one measured value?*
- **Why split C6:** the owner asked for the three types to be taught easiest first, with an explicit E-row-first method and a full tiny-K case. With those additions one video would run well over 10 minutes and crowd two different skills (finding K, finding concentrations). C6a finds K (types 1 and 2, plus reversal); C6b finds concentrations from K (type 3). Each has one main question, its own attempt and its own key notes.
- **Site source used:** as for C6: `site-extracts/chem-m5-l10.md` and `C:/Users/kygs/hscscience/subjects/chemistry/year12/module5/lesson10.sa.html` ("Calculating Keq, Substitution & ICE Tables"). The site's order is kept: direct substitution first (the site's "substitution" section is type 1), then the ICE table. The site's eight-step procedure ("find the change from the one given equilibrium value") is the type 2 method; this design makes that step explicit as "write it in the Equilibrium row, then subtract".
- **The three types (learner-visible, scene 1, scene 13, key note 1):** type 1, every equilibrium concentration is given: write the expression and substitute; type 2, the start and one equilibrium value are given: ICE table, then K; type 3, K and the start are given, and the equilibrium concentrations are asked for: an unknown x (C6b). The card picture is a mini ICE table showing which rows the question fills in, so the learner sees the difference rather than reads it. G03 uses the same numbering for these three types.
- **Cause chain taught, in order:** (1) what the question gives decides the method, because K needs every equilibrium concentration and the question may give them, give one, or give none (1); (2) type 1: write the expression with coefficients as powers and substitute the equilibrium concentrations (2); (3) K belongs to the equation as written: reverse it and K becomes 1 / K; double every coefficient and K is squared (3); (4) type 2: K uses concentrations, so divide moles by litres for the Initial row (5); (5) the measured equilibrium value goes into the Equilibrium row, and the table gives its change as equilibrium minus initial (6); (6) the other changes follow the coefficients, because each splitting event uses and makes whole particles in the ratio of the equation: used up is minus, made is plus (7); (7) every other equilibrium value is initial plus change (8); (8) K from the Equilibrium row only, and a check that the start is recovered (9, recorded find-k); (9) the two habits (10); (10) the attempt (11) and feedback naming the likely wrong answers (12a to 12c).
- **Entry knowledge:** C1 to C5 and Year 11. The learner knows the C2 PCl5 flask (0.20 mol/L start, settling at 0.12, 0.080, 0.080), the C4b hot H2 + I2 tube (dots 9, 9, 0 settling at 2, 2, 14), K as products over reactants with coefficients as powers, solids and the solvent left out, the size of K (C5), and from Year 11 c = n / V and mole ratios. Nothing about ICE tables or x is assumed.
- **Start and stop:** starts with "which of three types is this calculation?"; stops after the learner can find K for type 1 and type 2 (with the E-row-first ICE method and a check) and can say how K changes when the equation is reversed or its coefficients are multiplied. No type 3 (C6b), no Q (C8), no temperature dependence (C9).
- **Handoff:** chem-m5-c06b, type 3: finding equilibrium concentrations from K and a start.
- **Learner-visible definitions:** ICE table (a column for each substance and three rows: Initial for the start, Change for what the reaction does, Equilibrium for the settled mixture); concentration in mol/L (moles divided by litres); "used up" (minus) and "made" (plus); change (equilibrium minus initial).
- **Units policy:** unchanged from C5 and C6. Column headings carry mol/L; K is written without a unit, with the quiet tag "K: no unit written" at each substitution (HSC answers do not write a unit on K).
- **Examples and why:** type 1 is the C4b/C6 H2 + I2 settled tube in mol/L (one dot = 0.05 mol/L: 2, 2, 14 dots are 0.10, 0.10, 0.70) so the learner recognises it and the recorded reversal take applies to it unchanged. C5 checked the same tube on the "units" scale; here it is in mol/L, so the callback is one clause. Type 2 is the recorded PCl5 flask (0.40 mol in 2.0 L, [Cl2] = 0.080 at equilibrium), unchanged numbers. The attempt is the recorded N2O4 attempt (0.100 mol in 2.00 L, [NO2] = 0.0300 mol/L; K = 0.0257 and the reversed K = 38.9), unchanged.
- **Mistake scene:** none separate (AGENTS rule: optional). The wrong instincts (using initial values in K, treating the measured value as the change, not applying the coefficient, forgetting the volume, forgetting a power, keeping K for the reversed equation) are corrected in scenes 2, 3 and 5 to 10 and in the feedback.
- **Memory aids** (bank `docs/production/module5-memory-aids-2026-10-11.md`, a draft): "Only the C row follows the coefficients" (ICE section) as "Only the change row follows the coefficients"; "Work in concentrations, not moles" (trap); "Flip the equation, flip K. Multiply the equation, power K." (expressions section). New for this lesson: "Measured value: Equilibrium row first." See Memory aid check.
- **Reuse (no prototype components):** the C6 explainer board (paper stage, task line, equation strip, grouped givens card, ICE table component from `src/explainer/lessons/chem-m5-c06/ice.tsx`, givens card and fraction parts from `parts.tsx`, the PCl5 lens and hot tube from `board.tsx` and `parts.tsx`, the C5 expression builder, the countdown ring, the key notes board, the painted C2 flask and the painted N2O4 vessel pair). Scene components that already exist (`s1.tsx` to `s5.tsx`) are reused for the reused takes, with the changes listed in each Visual paragraph. New: the three type cards (coded, each with a mini ICE table) and the E-row-first arrow (a pen arrow from the givens card into the Equilibrium cell, then an "E minus I" bracket up to the Change cell). One visual system.
- **Author notes (not learner copy):** (a) PCl5 values are illustrative (C2 fact check: textbook Kc near 0.04 at about 250 C); the site's K = 65.0 for the reverse reaction disagrees, recorded in the C6 owner notes. (b) K for H2 + I2 is unit-free; for PCl5 and N2O4 it strictly has mol/L; HSC convention omits it. (c) "Change = equilibrium minus initial" holds per species; for a product that starts at zero the change equals the measured value, which is why the old wording ("it rose from zero to 0.080") gave the right number but hid the method; for a species that starts non-zero (G03 type 2 and the addition problems) the subtraction matters, which is the reason for the owner's rule. (d) The change row is a change in concentration; in a sealed vessel this is the change in moles over one volume, so the ratio is the mole ratio. (e) Pronunciation as C6: "I C E" letter by letter, "P C L five", "H I", "N two O four", "N O two", "nought point". Check that "I for initial" is not heard as the pronoun at a sentence start (it follows a colon, so it should be read as the letter). (f) The 0.10, 0.10, 0.70 tube has the same K = 49 as C5 because the powers cancel for this equation; C5 used units, C6a uses mol/L.

### 1. hook-types (three types of question)
> You can write K for any equation. Now we put numbers in. Almost every question that asks you to calculate with K is one of **three types**, and what the question gives you tells you which. **Type one** gives you every concentration at equilibrium, so you substitute straight into K. **Type two** gives you the start and just **one** value at equilibrium, so you need a table to find the rest first. **Type three** gives you **K and the start**, and asks for the concentrations at equilibrium. We'll take them easiest first: types one and two in this video, and type three in the **next**.

Visual: heading "Calculating with K: three types" writes on. Three cards build in a column on the left, one on each "Type" cue, each with a one-line label and a mini ICE table (three rows, two or three columns, no numbers, just shaded cells) that shows what the question fills in: card 1 "Every equilibrium concentration given: substitute into K" (only the Equilibrium row shaded, a K chip with "?"); card 2 "Start + one equilibrium value: ICE table, then K" (Initial row shaded and one Equilibrium cell shaded, the rest dashed, K "?"); card 3 "K + start: find the equilibrium concentrations" (Initial row shaded, a filled K chip, Equilibrium row all "?"). ### 2. type-one (every concentration given)

If a type one question gives moles in a vessel, divide by the volume first, because K uses concentrations.

### 3. reverse-equation (reuse take: reverse-equation)
> K belongs to the equation as it is written. Take the same settled tube, 0.10, 0.10 and 0.70, and write the equation **backwards**: two H I making hydrogen plus iodine. K is now hydrogen times iodine over H I squared: 0.10 times 0.10, over 0.70 squared, is **0.010 over 0.49**, about 0.020, and that is **one over 49**. Flip the equation, flip K. **Double** every coefficient and every power doubles, so K is squared: 49 squared is 2401.

### 5. ice-initial (the I C E table and the initial row)
> To keep track of every concentration, we use an **I C E table**: **I for initial**, **C for change**, and **E for equilibrium**. It has a column for each substance and a row for each of those three stages. We fill the **initial row** first. K uses concentrations, not moles, so divide: **0.40 moles over 2.0 litres is 0.20 moles per litre** of P C L five, and the two products start at **zero**.

### 12a. feedback-one (item one, E row first)

### 13. decision-rule (types one and two, and the handoff)

### 14. key-notes (reuse take: key-notes; quiet, hold about 50 seconds)
> Here are the key notes. Pause the video if you need more time to copy them.

- Three types of K calculation. Type 1: every equilibrium concentration is given, so substitute into K. Type 2: the start and one equilibrium value are given, so use an ICE table, then K. Type 3: K and the start are given, so find the equilibrium concentrations with x (next video).
- K uses concentrations in mol/L (moles divided by litres), coefficients as powers, and equilibrium values only. Leave out pure solids, pure liquids and water as the solvent. No unit is written for K.
- Type 2 order: start in the Initial row; the measured value in the Equilibrium row; its Change = equilibrium minus initial; the other changes from the coefficients (used up is minus, made is plus); complete Equilibrium = Initial + Change; substitute; check.

- K belongs to the equation as written, at one temperature. Reversed: K becomes 1 / K. Every coefficient multiplied by n: K goes to the power n.
