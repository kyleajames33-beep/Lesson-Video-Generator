### 1. hook: can it reach twelve dollars?
> Here are those caps. The average cost per cap is ninety over n, plus twelve. Order ten caps, and it's twenty-one dollars each. Order thirty, and it's fifteen. Ninety caps, thirteen dollars. It keeps falling towards twelve, but it never gets there, because ninety over n is never zero. The line A equals twelve is an asymptote, a line the graph gets closer and closer to without reaching. It came from y equals one over x, whose asymptote was y equals zero. The slide up twelve carried it up to **twelve**. When a graph moves, its features move too, but not all in the same way. That includes the domain, the x-values the graph can use, and the range, the y-values it reaches. So how do we track domain, range, intercepts and asymptotes through **transformations**?

### 2. carry the frame
> Here's the method on y equals three over, x minus two, plus one. From y equals one over x, that's a vertical stretch by three, a slide right two, then a slide up one. First, carry everything that rides along with the moves: the asymptotes, the key points, the domain and the range. Together, call these the **frame**. Start with the asymptotes, as whole lines. The vertical asymptote x equals zero can only move sideways, because sliding a vertical line up or down leaves it exactly where it was. So the slide right takes it to x equals **two**. The horizontal asymptote y equals zero can only move up or down, so it rises to y equals **one**. Next, carry key points. One, one stretches to one, three, then moves to three, **four**. Minus one, minus one goes to one, minus two. The domain follows the sideways moves. One over x can't use zero, so this graph can't use two. The range follows the moves up and down, so y can't be one. At x equals two, the graph breaks into two pieces. That break is a **discontinuity**.

### 3. solve the crossings
> Intercepts are different. One over x never touches either axis, but this graph crosses both, so its crossings can't have been carried from anywhere. Find them by solving. For the y-intercept, put x equals zero. Three over minus two, plus one, is minus a **half**. For the x-intercept, put y equals zero. Three over, x minus two, equals minus one, so x minus two is minus three, and x is minus **one**. So carry the frame, then solve for the crossings.

### 4. a parabola: the intercept that floats away

From y equals x squared, that's a flip and a stretch by two, then right three and up four. The vertex carries from zero, zero to three, **four**. But the parent's x-intercept was at that vertex, so it's now at height four, nowhere near the axis. So solve. Minus two, bracket x minus three, all squared, plus four is zero, so x minus three, all squared, is two, and x is three plus or minus root **two**, about one point five nine and four point four one. For the range, y greater than or equal to zero flips to y less than or equal to zero, then rises four, so it's y less than or equal to **four**. Saying the x-intercept stays at three is the **slip**.
