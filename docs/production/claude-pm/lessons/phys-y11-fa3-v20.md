### 2. one path, one current
> They all read the same. A series circuit has only one path, so every coulomb that passes the first ammeter has to pass the other two. Watch the three counters: they tick at exactly the same rate. And charge can't build up anywhere along the way. If more charge went into a resistor each second than came out, it would pile up inside, and it doesn't. So the same number of coulombs passes every point each second. That's the same current, everywhere in the **loop**.
