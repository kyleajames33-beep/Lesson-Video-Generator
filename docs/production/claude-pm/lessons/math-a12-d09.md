- **Author notes (not learner copy):**
  (a) First-derivative test as used here: if f is differentiable on an open interval around c (except possibly at c, where f is continuous), f′(c) = 0, and f′ > 0 on (c − δ, c) and f′ < 0 on (c, c + δ), then f has a local maximum at c; reversed signs give a local minimum. If f′ has the same sign on both sides, f is strictly monotonic through c, so c is not a local extremum. One test value per interval is valid when f′ is continuous on that interval and has no zero inside it (intermediate value theorem). For the polynomial examples f′ is continuous everywhere; for eˣ/(x + 1), f′ is continuous on each of (−∞, −1) and (−1, ∞).
  (b) "Horizontal point of inflection" follows the syllabus wording ("where gradients have the same sign on both sides of the point"). For every function in this video it is also a true point of inflection (x⁴ − 4x³: f″ = 12x(x − 2) changes sign at 0; f′ = x(x − 2)² gives f″ = (x − 2)(3x − 2), which changes sign at 2; x³: f″ = 6x). A same-sign derivative alone is not a general proof of a change of concavity; the general test is the later concavity home (route stop). The narration does not mention concavity.
  (c) Intervals: the narration and cards use strict inequalities. Many texts also write closed intervals such as "increasing for x ≤ 1"; f is increasing on (−∞, 1] in the interval sense. Feedback does not cross out either form.
  (d) Scene 4's shape panels: y = −x² (+, 0, −; local maximum), y = x² (−, 0, +; local minimum), y = x³ (+, 0, +; horizontal point of inflection, increasing through it). The −, 0, − case is said in words ("or minus on both sides"), and scene 8's x = 0 is that case.
  (e) The scene 5 lower panel: f′(x) = 4x²(x − 3) on −1.5 ≤ x ≤ 4.5, y window −20 to 20. f′(−1.1) ≈ −19.8 and f′(3.4) = 18.5, so the derivative curve leaves the window below for x < −1.1 (approximately) and above for x > 3.43 (approximately); its minimum on (0, 3) is f′(2) = −16, inside the window. It touches 0 at x = 0 (a local maximum of f′, f″(0) = 0) and crosses at x = 3.
  (f) Scene 9: y = eˣ/(x + 1) is not defined at x = −1; y → −∞ as x → −1⁻ and y → +∞ as x → −1⁺. Window x −3 to 2, y −3 to 4: y(−3) = −e⁻³/2 ≈ −0.025, y(2) = e²/3 ≈ 2.463. The two values in the narration: y(−2) = e⁻²/(−1) = −e⁻² ≈ −0.135; y(−½) = e^(−½)/(½) = 2e^(−½) ≈ 1.213.
  (g) Pronunciations: "x to the fourth, minus four x cubed"; "f prime of x"; "four x squared, times x minus three"; "x e to the x, over x plus one, all squared"; "e to the x"; for A2's card f′(x) = x(x − 2)², "x, times the bracket x minus two, squared" (check in the pilot that the square is heard on the bracket only); "sixty-four"; "one point five"; "minus twenty-seven". No "ln" in this video.

### 3. stationary is not the same as turning
> Two words to keep apart. A stationary point is any point where the derivative is zero, so the tangent is horizontal. That's all it **says**. A turning point is where the curve changes direction. It's either a local maximum, higher than every nearby point on the curve, or a local minimum, lower than every nearby point. Local means compared only with points close by. So the point at three is stationary, and it's a turning point. The point at zero is stationary, but it's not a **turning point**.

### 4. the sign on each side decides
> So what decides it? The sign of the derivative on each side. If the curve rises into the point and falls after it, the sign goes from plus to minus. Nothing nearby is higher, so it's a local **maximum**. If it falls in and rises out, that's minus to plus, and nothing nearby is lower: a local **minimum**. And if the sign is the same on both sides, plus and plus, or minus and minus, the curve keeps going the same way. That's called a horizontal point of **inflection**. It's stationary, but it isn't a turning point.

### 5. why the sign changes at three but not at zero

The factor x squared is never negative, so it doesn't change the sign there, and x minus three is negative on both sides of **zero**.
