### 2. litres per hundred kilometres
> In Australia, fuel use is given as a rate, litres per hundred kilometres. It's the number of litres a vehicle uses for every hundred kilometres it drives. This hatchback's label says seven point five litres per hundred kilometres. So every hundred kilometres, its tank drops by seven point five **litres**. Per kilometre, that's a tiny number, zero point zero seven five litres. So, like per hundred grams for coffee, a hundred kilometres gives a handier number. Here's the twist. A lower number is better, because the car uses less fuel for the same distance. That's the opposite of pay per hour, where bigger wins. A car using six litres per hundred kilometres is more efficient than one using **nine**.

### 5. worked example: fuel and cost
