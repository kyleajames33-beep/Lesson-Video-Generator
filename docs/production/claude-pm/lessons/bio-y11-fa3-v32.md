### 2. three tests
> You judge sampling data on three things. Validity asks whether the method measures what it claims, for example, whether the sample could represent the whole area. Reliability asks whether repeating the method gives similar results. Accuracy asks how close the result is to the true value. They sound alike, but they can disagree, so test each one separately.

Visual: the three-test card writes across the centre, one chip per cue: on "Validity" "valid?" with the gloss "measures what it claims; sample could represent the area"; on "Reliability" "reliable?" with "repeats agree"; on "Accuracy" "accurate?" with "close to the true value". Each chip carries a small coded glyph: a map with scattered squares (valid), three close dots (reliable), a dot on a target line (accurate). On "they can disagree" the three chips separate slightly with thin gaps between them (label "test each separately"). The card then shrinks to the top left, where it stays. At most three bright items. Hold one second.

### 6. validity explains it

And in real fieldwork, you rarely know the true value, so you judge validity from the method itself.

### 10. making the judgement
> So finish every evaluation the same way. Name the flaw, say whether it harms validity, reliability or accuracy, say which way it pushes the result, then state how far you'd trust the conclusion. Don't just add a caution.

### 13. key notes (quiet, about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

- Validity: the method measures what it claims; the sample could represent the area (random, whole area). Reliability: repeats agree (more samples and repeats). Accuracy: close to the true value.
- Reliable is not accurate: Group B (greenest corner) spread about 2% but 66% too high; Group A (random) spread about 8%, within 0.3% of 1850. Repeats fix scatter, not bias.
- In the field the true value is rarely known, so judge validity from the method.
- Recapture (N = M × C ÷ R): marks washing off → R too small → N too high. Few marks or one recapture → unreliable. One corner only → invalid.
- A change is supported only with the same valid method, season and places, and a change bigger than the scatter between repeats. Evaluate: flaw → which test → which direction → how far to trust → fix. Reject a biased design's whole-area estimate.
