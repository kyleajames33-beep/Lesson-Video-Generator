### 2. a complete path
> First, the rule underneath it all. Charge only flows round a complete path: out of one terminal of the cell, through the components, and back into the other. Open a gap anywhere, with a switch or a broken filament, and charge can't cross it. It can't keep piling up at the gap either, so the drift quickly stops all the way round the loop. No complete path, no **current**.

### 3. series: one path
> In series, the components are joined one after another, in a single loop. There's only one path, so every coulomb passes through every globe in turn. And since current isn't used up, the same current flows through each one. Now break one globe. The only path is broken, so the current stops everywhere, and every globe goes out. That's the old fairy **lights**.

### 4. parallel: a path each

That's how a house is **wired**.

### 5. sharing the energy, and why homes use parallel
> So side by side, one globe can go out on its own. There's another difference. In parallel, each branch connects straight across the cell, so every coulomb gets the cell's full voltage, whichever branch it takes. In series, each coulomb passes through both globes, so its energy is shared between them. That's why a house uses parallel. Every appliance gets the full supply voltage, and each one can be switched on and off by **itself**.

### 8. reading a diagram
> To read a diagram, trace the path from one terminal. If you pass through every component, one after another, with no junction, they're in series. If the path splits at a junction and the parts rejoin, the components on those branches are in parallel. Here, the path splits before R one and R two, and joins up again after them. > Here are the key notes. Pause the video if you need more time to copy them.

1. Charge flows only round a complete path. A break anywhere in a loop stops the current all the way round that loop.
2. Series: components one after another in a single loop. One path, so the same current through each, and the cell's energy per coulomb is shared. One break stops everything.
