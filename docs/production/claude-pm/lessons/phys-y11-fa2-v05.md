### 2. speed from one period
> Speed is distance travelled divided by the time taken. In one period, the wave moves on one wavelength. So the wave's speed is the wavelength divided by the **period**. For the cord, that's one point five oh metres in zero point five oh seconds, three point oh metres per **second**. For the spring, it's one point oh oh metre in the same half second, two point oh metres per second. So the cord's wave is faster, and that's why its waves are longer. Each crest gets further before the next one starts. This is the speed of the pattern. On this cord, the energy travels at that speed too. Each particle still only moves back and forth near **home**.

### 3. counting waves in one second: v = f lambda
> There's another way to get the same speed. Stand at one post, and count. Say three waves pass the post each second, and each wave is two metres long. Then six metres of wave go past every second. That's a speed of six metres per second. So the speed is the frequency, how many waves pass each second, times the wavelength, how long each one is. That's the wave **equation**: v equals f lambda. And because f is one over T, it's the same as lambda over T, the rule we just used. Check the units. Hertz means per second, so hertz times metres gives metres per **second**.

### 6. the medium sets the speed
> The same speed. The speed of this wave is set by what it travels through, its medium. For a cord, that's how tight it's pulled and how heavy it is. The driver only sets how often the waves are made. So doubling the frequency can't speed the crests up. Instead, each crest has only half as long to move on before the next one starts, so the wavelength **halves**, to zero point seven five metres. Four point oh times zero point seven five is still three point oh metres per second. So on this cord, at the same tension, frequency and wavelength trade. Double one, and the other halves. Sound in air behaves the same way, which is why a high note has a shorter wavelength than a low **note**.
