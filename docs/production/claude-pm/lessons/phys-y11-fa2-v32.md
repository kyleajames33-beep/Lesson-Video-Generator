### 2. both ends are nodes
> Let's find out why only certain frequencies work. The string is clamped at both ends, and a clamped end can't move, so both ends must be nodes. Each loop runs from one node to the next, so the string has to hold a whole number of loops. One and a half loops won't fit, because then the clamp would have to swing. The number of loops is called the harmonic number, n, and n loops have n plus one nodes, counting both ends. One loop is the fundamental, the lowest frequency that gives big, steady loops. Together, these allowed patterns are called **harmonics**.

### 4. the allowed wavelengths
> Three point oh oh. A loop is only half a wavelength, so one loop means the string's length is half a wavelength. In general, the length holds n half-wavelengths, so L equals n times lambda over two. Rearranged, lambda equals two L over **n**. For this string, that's three point oh oh metres, then one point five oh, then one point oh **oh**. Notice the pattern: each harmonic's wavelength is the fundamental's divided by n, a half of it, then a third.

### 5. the allowed frequencies
> Now the frequencies. The wave speed depends on the string itself, on how tight it is and how heavy it is per metre, not on the frequency. So every harmonic on this string travels at the same speed, thirty metres per second. Since v equals f lambda, the frequency is the speed divided by the wavelength. That gives ten hertz, then twenty, then **thirty**. Each is a whole-number multiple of the fundamental. At any frequency in between, the reflections from the two ends don't arrive in step, so they never build up into big loops, and the string only shakes a **little**.

### 6. working backwards: the wave speed
> You can also run this backwards, which is how you'd analyse a real string when you don't know the speed. Turn the dial until three loops appear, and read the frequency: thirty hertz. Measure the string: one point five oh metres. Three loops are three half-wavelengths, so lambda is two times one point five oh over three, one point oh oh metres. Then v equals f lambda, thirty times one point oh oh, thirty metres per **second**. Now do the same with one loop at ten hertz. Lambda is three point oh oh metres, and the speed comes out at thirty metres per second **again**. That's the evidence that the string, not the frequency, sets the **speed**.

### 7. back to the half-length string
> Now the hook. Halving the length halves every allowed wavelength, and the speed hasn't changed, so every frequency doubles. One loop now appears at twenty hertz. That's exactly how a guitar works. Pressing a string at its midpoint halves the length that vibrates, so the note jumps to double the frequency, which we hear as the same note, higher. That's called an octave. Tightening the string makes its waves travel faster, so every frequency rises. That's how a guitar is tuned. And heavier strings carry slower waves, so they play lower **notes**.

### 15. key notes (quiet, hold about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

1. A string fixed at both ends has a node at each end, so it holds a whole number n of loops (half-wavelengths): L = nλ/2, so λ = 2L/n.
2. n is the harmonic number (the number of loops). n = 1 is the fundamental: λ₁ = 2L, the lowest frequency.
3. The wave speed v is set by the string (tension, mass per metre), the same for every harmonic. Then f = v/λ, so the allowed frequencies are whole-number multiples of f₁.
4. Halving L doubles every frequency (an octave). A tighter string: faster waves, higher frequencies. A heavier string: lower frequencies.
5. Method: draw the loops, find λ from L, then f = v/λ.

## Practice questions and model answers

**Attempt 1 (scene 10; original wording, HSC style, 3 marks suggested, not an official marking scheme).** "A string of length 0.90 m is fixed at both ends. Waves travel along the string at 180 m s⁻¹.
