### 2. both ends are nodes
> Let's find out why only certain frequencies work. The string is clamped at both ends, and a clamped end can't move, so both ends must be nodes. Each loop runs from one node to the next, so the string has to hold a whole number of loops. One and a half loops won't fit, because then the clamp would have to swing. The number of loops is called the harmonic number, n, and n loops have n plus one nodes, counting both ends. One loop is the fundamental, the lowest frequency that gives big, steady loops. Together, these allowed patterns are called **harmonics**.

### 4. the allowed wavelengths
> Three point oh oh. A loop is only half a wavelength, so one loop means the string's length is half a wavelength. In general, the length holds n half-wavelengths, so L equals n times lambda over two. Rearranged, lambda equals two L over **n**. ### 5. the allowed frequencies
> Now the frequencies. The wave speed depends on the string itself, on how tight it is and how heavy it is per metre, not on the frequency. So every harmonic on this string travels at the same speed, thirty metres per second. Since v equals f lambda, the frequency is the speed divided by the wavelength. That gives ten hertz, then twenty, then **thirty**. Each is a whole-number multiple of the fundamental. At any frequency in between, the reflections from the two ends don't arrive in step, so they never build up into big loops, and the string only shakes a **little**.

### 6. working backwards: the wave speed

### 7. back to the half-length string

Tightening the string makes its waves travel faster, so every frequency rises. That's how a guitar is tuned. And heavier strings carry slower waves, so they play lower **notes**.

## Teaching checks

- **Does it explain causes?** Why only whole loops: both clamped ends must be nodes, and a half loop would need the clamp to move (2).
