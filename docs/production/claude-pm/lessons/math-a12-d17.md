- **Learner question kept (route).** "How do the function and its two derivative graphs constrain a sketch?" The answer, built in order: three marked points allow many curves (hook); the sign of f′ on each interval fixes the direction, so a curve that rises where f′ < 0 is ruled out (2); the sign of f″ fixes the bend, so a straight or wrongly bent join is ruled out (3); symmetry, intercepts and end behaviour fix the rest, and the checklist is the list of these rules (4, 5); an excluded value can split the graph, carry an asymptote and stop a concavity change from being an inflection (6, 7); read in reverse, the gradient of each graph draws the next one down (8, 9).

## Practice questions and model answers

**Attempt 1 (scene 11; original wording, HSC style, 3 marks suggested, not an official marking scheme).** "Consider f(x) = x − 4/x. (a) State the domain of f and whether f is odd, even or neither. (b) Show that the graph of y = f(x) has no stationary points. (c) Does the graph have a point of inflection? Justify your answer."
Model answer: (a) x ≠ 0; f(−x) = −x + 4/x = −f(x), so f is odd. (b) f′(x) = 1 + 4/x² > 0 for every x ≠ 0, so f′(x) is never zero: no stationary points. (c) f″(x) = −8/x³, which is positive for x < 0 and negative for x > 0, so the concavity changes only across x = 0. Since 0 is not in the domain, there is no point there, so there is no point of inflection. Classic mistake (crossed): "point of inflection at (0, 0)".

**Attempt 2 (scene 13; original wording, HSC style, 2 marks suggested).** "The graph of y = f(x) is shown. (a) State the values of x for which f′(x) = 0. Model answer: (a) f′(x) = 0 at x = −1 (f turns from decreasing to increasing, so f′ crosses the axis from negative to positive) and at x = 2 (f is flat but keeps increasing, so f′ touches the axis without changing sign).
