### 2. why sequences record ancestry
> When one species splits into two, both new lineages start with the same copy of each gene. From then on, each lineage collects its own random changes in DNA, called mutations, and they aren't shared. So the longer ago two species split, the more differences build up between their copies of the same gene. Fewer differences means a more recent common ancestor.

Visual: the helix shrinks to the top right. A coded ancestor row of twelve base tiles sits at a branch point (grey tag "v04: one species splits into two"); on "splits into two" the row copies onto two branches that grow upward. On "mutations" a gloss writes "mutation: a random change in DNA"; tiles flip colour one at a time, first on the left branch, then the right, never the same tile on both (each flip flashes amber). A small counter between the branch tips reads "differences: 1, 2, 3, 4". On "the longer ago" the branches grow taller and two more tiles flip (counter 6). On "Fewer differences" an amber principle chip writes: "fewer differences → more recent common ancestor" (it stays to scene 13). At most three bright items. Hold one second.

### 14. key notes (quiet, about 60 seconds)
Heading on screen: "Key notes: what to write in your book".
> Here are the key notes. Pause the video if you need more time to copy them.

- After two lineages split, each collects its own mutations (random changes in DNA). Fewer differences in the same gene or protein → more recent common ancestor → more closely related.
- Compare homologous sequences: the same gene or protein, inherited from the shared ancestor.
- Method: obtain sequences (public database) → align (insert gaps) → count differences for every pair → difference matrix → join the smallest counts first → check the tree against the matrix → repeat with another gene or protein.
- A list against one species (for example, humans) never compares the others with each other: it cannot give the whole tree.
- Assumptions and limits: differences build up at a roughly steady rate (molecular clock), correct alignment; short or slow-changing sequences can't resolve close branches. A tree is a supported hypothesis; agreement between independent genes makes it more reliable.
