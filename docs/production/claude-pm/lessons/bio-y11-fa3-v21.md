### 2. why sequences record ancestry
> When one species splits into two, both new lineages inherit matching copies of each gene from their shared ancestral population. From then on, each lineage collects its own random changes in DNA, called mutations, and they aren't shared. So the longer ago two species split, the more differences build up between their copies of the same gene. So, under this model, fewer differences suggests a more recent common ancestor.
