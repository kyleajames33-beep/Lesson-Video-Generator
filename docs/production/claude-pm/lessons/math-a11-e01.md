### 3. the features of y = 2ˣ
> Let's read the features off y equals two to the x. Where does it cross the y-axis? At x equals zero, so at zero, **one**. Now follow the curve to the left. Each step left halves the height, a half, a quarter, an eighth, and halving never reaches zero. So the curve gets closer and closer to the x-axis, without ever reaching it. A line like that is called an asymptote. Here, it's y equals **zero**. You can put any x into two to the x, so the domain is all real x. But every output is positive, so the range is y greater than **zero**. And the behaviour at each end? As x goes to infinity, y grows without bound, which means it gets as large as you like. As x goes to minus infinity, y heads towards **zero**.

### 4. the base, and the minus sign
> Now change the base. A base bigger than one gives a curve that rises to the right. A bigger base climbs more steeply to the right of the y-axis, and hugs the x-axis more closely on the **left**. A base between zero and one, like a third, gives a curve that falls to the right. It still passes through zero, one, because a third to the zero is also **one**. The base can't be one, because one to any power is one, and that's just a flat line. It can't be zero, because zero to any positive power is just zero. And it can't be negative, because a negative base has no real value at powers like a half. Now put a minus sign in the power. A to the minus x is one over a, all to the x. So the minus sign doesn't make the values negative. It reflects the graph in the y-**axis**. Two to the minus x falls to the right, exactly like a half to the **x**.

### 5. the number in front, k

Every height is multiplied by a negative number, so every point flips below the x-**axis**. Its y-intercept is zero, minus two. The asymptote is still y equals zero. But now the range is y less than **zero**, and as x goes to infinity, y heads down without bound. So k sets where the curve crosses the y-axis, and which side of the x-axis it's on. The base sets its **shape**.

### 6. worked example: finding k and a
> Let's use that to find an equation. An exponential curve, y equals k times a to the x, passes through zero, three, and one, six. Find k and a. Start with the y-intercept, because a to the zero is one. At x equals zero, y equals k, so k is **three**. Now use the second point. At x equals one, six equals three times a, so a is **two**. The equation is y equals three times two to the **x**. Check it. At x equals one, three times two is six. That works. Writing the y-intercept as zero, one is the slip. That's only true when k is **one**.
