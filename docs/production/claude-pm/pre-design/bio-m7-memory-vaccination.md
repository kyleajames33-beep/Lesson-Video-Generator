## 2. Site order, ideas, examples, practice and memory aids

Primary/secondary response precedes safe antigen exposure, four immunity types, population protection, control/elimination/eradication and measles data. Active immunity follows the recipient’s own response; passive immunity supplies antibodies. Natural/artificial acquisition are a separate axis. Practice evaluates vaccination evidence with actual values.

**L13 page sequence:** The experiment that started it.; First time versus every time after.; Engineering a safe first exposure.; vaccination and memory.

**L14 page sequence:** Four kinds of immunity.; Annotated Diagram, The Four Types of Immunity.; Protection you get from other people.; Control, elimination, eradication.; Evaluate vaccination program evidence.; Data Analysis, Measles Cases and Vaccination Coverage.; Consolidate population immunity.
