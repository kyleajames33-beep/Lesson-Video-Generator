## 2. Site order, ideas, examples, practice and memory aids

**L19 order:** Connect: analyse the target molecule; Explain: navigate the complete reaction map; Represent: use a pathway algorithm; Respond: build pathways from simple to complex; Feedback: avoid dead ends and condition traps; Apply: reveal a complete synthesis step by step.

**L19 key ideas:** 1. , Before You Read.
2. By L19 you have learned 15+ individual reaction types.
3. 1, The Complete Reaction Map: Every Arrow You Have Built.
4. A multi-step pathway problem is not solved by intuition, it is solved by a systematic algorithm: identify functional groups of start and end, find a valid connected path on the map, then write each step with full conditions.
5. 2, The Systematic Approach: Four-Step Algorithm for Pathway Problems.
6. The best way to internalise the algorithm is to apply it to progressively more complex examples, starting with two-step paths and building toward four-step syntheses.
7. 3, Pathway Drills: Building From Simple to Complex.
8. The hardest pathway questions give you an unfamiliar starting material and expect you to use functional group identification + the reaction map to construct a valid route, this card builds that skill explicitly.

**Worked problems:** Problem: Identify the reagents and conditions for each step. Name all intermediates. ## 3. Number and science check

Example1 ethanol -> ethanoic acid -> ethyl ethanoate. Example2 bromopropane -> propanol -> propanal by distillation or propanoic acid under reflux. Example3 bromobutane -> butanol -> butanal -> butanoic acid -> butyl butanoate. Butanol from step1 must be retained as a separate portion for esterification. Four steps are requested, not chemically minimal: direct reflux oxidation bypasses isolated aldehyde. Site butanal75/butanol118 degrees C and ester yield about65% are reference claims; yield cannot be calculated without quantities and conditions. Each equation conserves atoms with1[O] for aldehyde-to-acid and2[O] for alcohol-to-acid. L20 contributes flawed-pathway diagnosis and a seven-mark synthesis.
