## 2. Site order, ideas, examples, practice and memory aids

**Teaching order.**

**L16:**

1. A restriction enzyme cuts a selected DNA fragment and a vector at compatible sites.
2. DNA ligase joins the fragment to the vector; the vector carries recombinant DNA into a host cell.
3. The host copies or expresses the inserted gene to make DNA copies, a protein or a transgenic product.
4. PCR can amplify a target sequence and a gel can separate fragments by size as supporting techniques.
5. Directly inserted DNA distinguishes a transgenic organism from one produced only by controlled breeding.

**Worked examples and numbers from the extracts.**

**L16:**

- The Humulin example traces a human insulin sequence through a plasmid into *E. coli*, which produces insulin precursors for processing and purification.
- A six-mark description orders isolation, vector preparation, ligation, host transfer and selection. Another six-mark answer explains shared genetic code, a host-recognised promoter, intron-free cDNA and suitable protein processing.

**Practice.**

**L16:** Toolchain sequencing, product comparison, an interactive benefit-risk sorter, multiple choice, two guided answers and three short answers. Representative question: “Describe the techniques used to produce a recombinant DNA molecule and introduce it into a host cell.”

The extracts record no named mnemonic unless shown above. Keep any useful contrast or question from the page; do not manufacture a memory aid.

## 3. Number and science check

The original Genentech insulin route used synthesised DNA for A and B chains, bacterial expression, and later combination. The page’s claim that Humulin first used a human cDNA library is historically wrong. Relevant site-correction register entries: L16. Use the corrected statements in that register. Source for flagged corrections: [Module 6 site corrections](../site-corrections-m6.md).

**Site correction:** Site L16 says the original Humulin route began with human cDNA. The original Genentech process synthesised DNA for separate insulin A and B chains, expressed them in bacteria and combined the recovered chains. See [Module 6 site corrections](../site-corrections-m6.md) for the source and replacement statement.

## 4. Exam traps and student mistakes

**L16:**

- Recombinant DNA is simply mixing DNA. Cutting, joining, vector transfer and host use have distinct roles.
- A transgenic organism is just selectively bred. It contains directly introduced DNA.
- Any restriction enzyme works for any join. The page calls for complementary ends on fragment and vector.

These traps come from the linked site lessons. They are not attributed to NESA markers without a specific exam report.
