- **Ledger B6-IQ1-05:** "investigate the causes of genetic variation relating to the processes of fertilisation, meiosis and mutation (ACSBL078)". The ledger's combined depth-study-or-practical flag is true; it does not establish a required hands-on method. L06 explains all three processes but gives no hands-on procedure. This plan supplies a school-scale model.
- **Main question:** Which processes create a new allele, and which rearrange alleles already present?

## Aim and method

Use two colours of chromosome cards and labelled allele tiles to model meiosis in two parents, then combine gametes. Each parent starts `AaBb` with A/a on chromosome pair 1 and B/b on pair 2. Card strips are 10 cm long; each pair has a marked centromere. Make 16 paper gamete cards per parent: four `AB`, four `Ab`, four `aB`, four `ab`. To earn rather than assume these four types, turn each chromosome pair independently at metaphase I in repeated four-cell trials, separate homologues then sister chromatids, and record the gametes. A 1:1:1:1 composition is the teaching model's designed set, not a claim that 16 real gametes must have exactly equal counts.

Show crossing over separately on one duplicated A-bearing homologous pair: exchange equal distal coloured segments between **non-sister chromatids** at the same marked position before separation. Keep an allele marker on each side of the exchange, so the changed combinations can be seen. This demonstration is qualitative because its artificially chosen crossover is not a population recombination rate.

For fertilisation, number the four possible gamete types from each parent. Pair every maternal type with every paternal type in a 4 x 4 grid, giving 16 possible two-locus zygote combinations. This exhaustive grid displays theoretical combinations, not 16 independent births. Add one red `a*` tile to a single model gamete to represent one new DNA-sequence allele produced by mutation. Keep the mutant example outside the original 16-cell grid so the Mendelian calculation is not silently changed. Record source and result in three columns: meiosis reshuffles existing alleles; fertilisation joins two independently made gametes; mutation creates a new allele. Physical quantities: two sets of four 10 cm chromosome strips per parent, 32 gamete cards, 16 zygote spaces and one red mutation tile. No reagents or concentrations apply.

## Variables and computed expected results

For the exhaustive grid, the manipulated modelling step is independent assortment or gamete pairing. Outcomes are gamete and zygote combinations. Keep parental genotype, allele meaning, chromosome number and dominance assumptions fixed. Assume complete dominance at both unlinked loci only for the phenotype calculation.

Each parent has four equally likely types: `AB`, `Ab`, `aB`, `ab`, each 1/4. Combining two parents gives 4 x 4 = 16 equally likely pairings. At locus A, `Aa x Aa` gives 3/4 dominant phenotype and 1/4 recessive; likewise at B. Multiplying independent probabilities gives:

| Phenotype class | Working | Expected grid cells |
| --- | --- | ---: |
| A dominant, B dominant | 3/4 x 3/4 = 9/16 | 9 |
| A dominant, bb | 3/4 x 1/4 = 3/16 | 3 |
| aa, B dominant | 1/4 x 3/4 = 3/16 | 3 |
| aa, bb | 1/4 x 1/4 = 1/16 | 1 |

The four classes total 9 + 3 + 3 + 1 = 16. The complete genotype grid also gives nine genotype types: `AABB` 1, `AABb` 2, `AAbb` 1, `AaBB` 2, `AaBb` 4, `Aabb` 2, `aaBB` 1, `aaBb` 2, `aabb` 1. Their counts sum 1 + 2 + 1 + 2 + 4 + 2 + 1 + 2 + 1 = 16. The new `a*` tile produces an allele absent from both starting parents; meiosis and fertilisation alone cannot do that. Do not turn this one illustrative tile into an estimated mutation frequency.

If the class draws gamete cards at random rather than enumerating all possibilities, expect variation around these proportions. A 16-draw sample need not produce 9:3:3:1. Use the exact grid for the computed reference and the draw data for variability.

## Validity, reliability and accuracy

Validity: the model represents independent assortment and random pairing if A and B are on different chromosome pairs and each gamete contains one allele per locus. It does not represent actual mutation probability, linkage or a real species' chromosome count. Crossing over must occur between non-sister chromatids of homologues; exchanging arbitrary cards would misrepresent it. Reliability: repeat random gamete draws or compare groups using the same procedure, then pool results; repeated samples should tend towards the same proportions, though small samples fluctuate. Accuracy: a real measurement's closeness to a true value is not established by the 9:3:3:1 theoretical grid; for physical sorting, check all 16 combinations and allele labels against a prepared key to avoid transcription errors. These uses follow [NESA's VRA definitions and syllabus-version note](../research/exam-skills/vra-definitions.md).

## Common errors and improvements

- Showing allele shuffling as mutation: use a new-colour `a*` tile only for mutation; all other tiles come from the starting parents.
- Putting A and B on the same card while claiming independent assortment: put them on separate chromosome pairs, or calculate linkage explicitly.
- Calling a 9:3:3:1 outcome guaranteed in 16 real births: label the grid as theoretical and use repeated random draws to demonstrate sampling variation.
- Crossing over between sister chromatids or at unmatched positions: align homologues and exchange equal segments between non-sisters at the marked point.

## HSC-style question idea

Students receive the parental `AaBb` model and a completed 4 x 4 gamete grid. They calculate the probability of an `aabb` offspring, explain how meiosis and fertilisation give varied offspring, and identify which added tile actually represents a new allele. This is an original item, not a copied NESA question.
