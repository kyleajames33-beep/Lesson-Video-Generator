## 3. Biology context and stop boundary

Carrying out ws-v02's potato-cylinder osmosis plan: tare the balance, blot the same way every time, record raw masses in a table drawn before starting, keep the odd reading and note why; managing the scalpel and spills while working; gathering secondary data on the same question from more than one source and recording each source. Leaves the pondweed conduct to fa2-v07.

Stop: Managing risks while working (not only on paper); assembling and checking apparatus before data (zeroing, calibration, trial run); systematic recording: a raw-data table drawn first, units in headings, consistent decimal places, every reading including odd ones with a note, observations; gathering secondary data from a range of sources and recording where each came from. Not taught: processing (ws-v04), analysis statistics (ws-v05).

## 4. Numbers and facts

Illustrative raw table for ws-v02's potato cylinders: initial and final mass (g, two decimal places) at five concentrations, three cylinders each, one odd final mass kept with a note ('cylinder not blotted').

## 5. Misconceptions and traps

'Write the results up neatly afterwards' (record raw data at the time). 'Leave out the odd reading' (record it, note why). 'Copy a number from a website without its source'. 'Safety is done once the risk assessment is written'.
