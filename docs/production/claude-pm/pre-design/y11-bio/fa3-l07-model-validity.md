## 2. Site lesson content

Whole-page section order: The Predation Model, Method; What the Results Show; Discussing the Model's Validity; Comparing Various Models.

Selected material:
- Discussing the Model's Validity: To judge a model's validity we weigh how faithfully it represents the real process, listing what it captures well and what it simplifies or ignores.
- Comparing Various Models: A model is judged against the specific claim it is being used to support, so two models of the same process can both be valid while being valid for different things.

Practice: Run and Record the Model Pattern A, Structured practical record Carry out (or simulate) the model for four generations. In your book, make a results table with columns for Generation, Green survivors, Red survivors, and % green. Then write one sentence describing the trend and one sentence naming which controlled variable you kept constant (e.g. hunting time, background). Site short-answer demand: A class used coloured dots and a patterned background to model natural selection by predation. Discuss the validity of this model, giving two strengths and two limitations, and suggest one improvement.

## 4. Misconceptions and traps

Site misconception: - Misconceptions To Fix watch out ✗ Wrong: If a model produces the "right" result, it must be a fully valid representation of the real process. ✓ Right: A model can give the expected outcome while still being unrealistic in important ways (e.g. it may ignore mutation, mating, or environmental change).

Source-backed response trap: A model can show the predicted colour trend while still omitting mutation, mating and changing habitats. State what each limitation does to the claim. Source: site L07, misconception, activity and short-answer task. This is a page-based trap, not a claim about NESA marker trends.
