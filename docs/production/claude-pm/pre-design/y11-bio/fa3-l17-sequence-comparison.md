## 2. Site lesson content

Whole-page section order: Sequences Record Ancestry; The Investigation, Counting Differences; Reading the Tree & Its Limits.

Selected material:
- Sequences Record Ancestry: When two species split from a common ancestor, their DNA slowly accumulates separate mutations, so the longer ago they split, the more their sequences differ.
- The Investigation, Counting Differences: The method is straightforward: take the same gene or protein from each species, line them up, count the positions that differ for each pair, and record the totals in a table.

Practice: Activity 1 Analyse Band 5 Build the Tree from the Data Pattern B, Work with data Amino-acid differences in a conserved protein, compared to humans, are: chimpanzee 0, gorilla 1, mouse 9, chicken 18. Rank the four species from most to least closely related to humans, explain how the numbers justify your ranking, and sketch a simple tree (in words) showing the branching order from the human lineage. Site short-answer demand: Describe how you could use DNA or amino-acid sequences to infer the evolutionary relationships between three species, and explain one assumption and one limitation of the method.

## 3. Number and fact check

The activity ranks amino-acid differences from humans: chimpanzee 0, gorilla 1, mouse 9, chicken 18. The short answer uses 0, 1, 12, 21, 44 for chimpanzee, rhesus monkey, horse, tuna, yeast. Both orders run from fewer to more differences; a simple human-reference list alone cannot fully fix all relationships among the non-human species. No reference constant is used. Source: site L17.

## 4. Misconceptions and traps

Site misconception: - Misconceptions To Fix watch out ✗ Wrong: Species that look most alike must be the most closely related, so sequence data just confirms appearance. ✓ Right: Appearance can mislead (convergent evolution can make unrelated species look alike).

Source-backed response trap: Fewer differences in the same aligned sequence can support closer relation. A human-reference ranking alone cannot establish every branch among other species. Source: site L17, misconception, activity and short-answer task. This is a page-based trap, not a claim about NESA marker trends.
