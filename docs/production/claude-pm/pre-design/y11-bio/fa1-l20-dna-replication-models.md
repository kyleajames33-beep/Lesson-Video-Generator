## 2. Site order, ideas, examples, practice and memory aids

- **Assessing the Use of Models:** What a model shows well, and where it falls short Models make an invisible process easy to visualise and manipulate, but they simplify reality, assessing a model means weighing what it shows well against what it leaves out or distorts. Strengths: a physical model makes the abstract process visible; it lets you show the sequence of steps, the base-pairing rule, and each enzyme's role; it is interactive and helps memory. Limitations: the scale is wrong (real DNA is enormous and 3-D); it cannot show the true speed (~1000 bases per second) or accuracy; beads and string do not behave like real molecules, and it usually ignores proofreading and the antiparallel detail.

**Page activity:** Apply Band 4 Model It With Materials Pattern D, Plan and conduct Use paper strips, coloured beads, pipe cleaners or interlocking blocks to model replication. Build a short parent double strand, then "unzip" it and add complementary nucleotides to each template. In your book, record: what each material represented (e.g. beads = bases, string = backbone), where you showed helicase, primase, DNA polymerase and ligase acting, and which strand you built as…

**Practice:** Describe how a physical model can demonstrate DNA replication, naming the role of helicase, primase, DNA polymerase and ligase, and then assess the use of such models.

**Memory aid:** No named mnemonic is stated in the selected page cards. Use the page’s comparison or physical model where it helps recall the mechanism.

**Page misconception:** ✗ Wrong: Each new DNA molecule is made entirely of brand-new nucleotides, with both old strands discarded. ✓ Right: Replication is semi-conservative . Each new double helix keeps one original ("parent") strand and one newly built strand. The original strand acts as the template for the new one, which is why the copies are so accurate.
