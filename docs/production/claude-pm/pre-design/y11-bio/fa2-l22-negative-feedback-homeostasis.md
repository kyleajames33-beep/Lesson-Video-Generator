## 2. Site lesson material

Source: `C:/Users/kygs/hscscience/subjects/biology/year11/fa2-cells-to-systems/lesson22.sa.html` and `docs/production/claude-pm/site-extracts/bio-y11-fa2-l22.md`. Site section order: 1. What Negative Feedback Does; 2. Constructing the Loop Diagram; 3. Interpreting a Loop, Thermoregulation; 4. When negative feedback can't keep up. Relevant ideas:

- What Negative Feedback Does: Negative feedback keeps a variable steady by detecting when it drifts away from its set point and then triggering a response that pushes it back the other way.
- Constructing the Loop Diagram: A negative feedback diagram is a closed loop: each component passes information to the next, and the loop closes when the response returns the variable to the set point.
- Interpreting a Loop, Thermoregulation: A single negative feedback system corrects a variable whether it rises or falls, because the response always opposes the change in whichever direction it occurs.
- When negative feedback can't keep up: heatstroke: Negative feedback is powerful but not unlimited.
