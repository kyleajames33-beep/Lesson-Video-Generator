## 2. Site order, ideas, examples, practice and memory aids

- **Halving the Chromosome Number:** Two divisions, four cells, half the chromosomes Meiosis exists to make gametes, and to do that it must halve the chromosome number so fertilisation can restore the full set. Meiosis is a special cell division that occurs in the formation of gametes (sex cells). It involves two rounds of division, meiosis I and meiosis II, and produces four daughter cells, each with half the chromosome number of the parent cell (haploid). The DNA is replicated once (in interphase before meiosis I), but the cell divides twice, which is why the chromosome number is halved. Halving is essential so that when two gametes fuse at fertilisation, the full chromosome number is restored rather than doubling every…

**Page activity:** Apply Band 5 Model the Named Phases of Meiosis and Cytokinesis Pattern D, Hands-on model Using two colours of pipe cleaners (or modelling clay) to represent a maternal and a paternal homologous pair, model meiosis in order: prophase I (pair the homologues and model crossing over by swapping a segment), metaphase I (line the pairs up, independent assortment), anaphase I & telophase I + cytokinesis (separate homologues into two cells), then meiosis II…

**Practice:** Describe the processes of crossing over, independent assortment and random segregation during meiosis, and explain how each contributes to genetic variation.

**Memory aid:** No named mnemonic is stated in the selected page cards. Use the page’s comparison or physical model where it helps recall the mechanism.

**Page misconception:** ✗ Wrong: Meiosis produces two identical cells, just like mitosis, only with fewer chromosomes. ✓ Right: Meiosis produces four cells, each with half the chromosome number, and each is genetically different because of crossing over, independent assortment and random segregation. Identical daughter cells are the result of mitosis, not meiosis.

## 3. Number and science check

Human 2n = 46 and n = 23. Independent assortment gives 2^23 = 8,388,608 combinations before crossing over. A two-pair model yields 2^2 = 4.
