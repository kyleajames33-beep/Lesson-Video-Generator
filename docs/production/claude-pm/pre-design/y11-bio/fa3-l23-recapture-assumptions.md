## 2. Site lesson content

Whole-page section order: The Method & the Lincoln Index; Modelling It & Doing the Calculation; Assumptions & Sources of Error.

Selected material:
- Assumptions & Sources of Error: The Lincoln index is only valid if the marked animals truly behave like an unbiased random sample of the population the second time around.

Practice: Run the Numbers Pattern B, Work with data In a model, 60 beans were marked and returned. Three second samples gave: (C = 50, R = 12), (C = 48, R = 10), (C = 52, R = 14). (a) Estimate the population from each sample using N = (M × C) ÷ R. (b) Average the three estimates. (c) Explain why averaging several samples gives a more reliable result than relying on one. Site short-answer demand: An ecologist marked 80 frogs and released them. Two weeks later they caught 100 frogs, 20 of which were marked. Estimate the population using the Lincoln index, and explain two assumptions of the method and how breaking one would affect the estimate.

Memory aid: The page asks students to retain M, C, R and N = M×C/R.

## 4. Misconceptions and traps

Site misconception: - Misconceptions To Fix watch out ✗ Wrong: The population is just the number of animals you caught in total (first + second catch). ✓ Right: You never catch the whole population.

Source-backed response trap: Adding catches is not a population estimate. Marks must mix, remain visible and leave catchability unchanged; smaller R makes N larger. Source: site L23, misconception, activity and short-answer task. This is a page-based trap, not a claim about NESA marker trends.
