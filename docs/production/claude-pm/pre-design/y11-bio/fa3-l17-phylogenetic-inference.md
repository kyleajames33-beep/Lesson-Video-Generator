## 3. Number and fact check

The page ranks species by increasing sequence differences: 0, 1, 9, 18 from humans in the activity. A human-reference list does not alone resolve all non-human branch relationships. No reference constant is used. Source: site L17.

## 4. Misconceptions and traps

Site misconception: - Misconceptions To Fix watch out ✗ Wrong: Species that look most alike must be the most closely related, so sequence data just confirms appearance. ✓ Right: Appearance can mislead (convergent evolution can make unrelated species look alike).

Source-backed response trap: Fewer differences in the same aligned sequence can support closer relation. A human-reference ranking alone cannot establish every branch among other species. Source: site L17, misconception, activity and short-answer task. This is a page-based trap, not a claim about NESA marker trends.
