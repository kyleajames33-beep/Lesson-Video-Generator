## 2. Site lesson material

Source: `C:/Users/kygs/hscscience/subjects/biology/year11/fa2-cells-to-systems/lesson21.sa.html` and `docs/production/claude-pm/site-extracts/bio-y11-fa2-l21.md`. Site section order: 1. The Five Components; 2. A Worked Example; 3. Why the Components Must Connect; 4. Feedback control everywhere, from cruise control to insulin pumps. Relevant ideas:

- The Five Components: Every feedback system, biological or mechanical, is built from the same five parts arranged in the same order, learn them once and you can read any example.
- A Worked Example: Getting Cold: Walking through a single example shows how the abstract five-part framework becomes a concrete chain of events in the body.
- Why the Components Must Connect: Each component does a job no other can do, so removing any one breaks the system, which is why a "typical feedback system" always lists all five.
- Feedback control everywhere, from cruise control to insulin pumps: The same five-part logic runs a car's cruise control, a fridge thermostat and an aircraft autopilot, and, life-changingly, an artificial pancreas.

Practice demand: Site review sample: Which component of a feedback system detects a change?

Describe the key components of a typical feedback system, and analyse why the order of the components matters and why the system could not function if the control centre were removed.

Site memory/retrieval cue: You can now describe the five components of a feedback system and map any example onto them. Next lesson uses this framework to construct and interpret negative feedback loops that maintain homeostasis.
