## 5. Misconceptions and traps

'Controlled variable' and 'experimental control' used as synonyms (one is kept the same; the other is a comparison set-up that rules out another cause). 'More trials make it valid' (repeats improve reliability, not validity). 'A website is reliable if it looks professional'. 'Ethics only matters for experiments on people'.
