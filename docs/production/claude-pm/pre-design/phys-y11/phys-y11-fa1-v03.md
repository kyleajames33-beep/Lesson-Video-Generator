### Exact site example `we-1`

WORKED EXAMPLE · RESOLVING A FORCE A rope pulls a sled with a force of $100\ \text{N}$ at $30°$ above the horizontal. Find the horizontal and vertical components of this force. 1 GIVEN: $F = 100\ \text{N}$, $\theta = 30°$ to the horizontal. FIND: $F_x$ and $F_y$. The angle is measured from the horizontal $x$-axis, so $x$ uses cosine. 2 METHOD: resolve along each axis. $$F_x = F\cos\theta, \qquad F_y = F\sin\theta$$ $F_x$ drags the sled forward; $F_y$ lifts it (reducing the normal force). 3 ANSWER: $$F_x = 100\cos 30° = 86.6\ \text{N}$$ $$F_y = 100\sin 30° = 50.0\ \text{N}$$ Check: $\sqrt{86.6^2 + 50.0^2} = 100\ \text{N}$ ✓, the components recombine to the original force. 1 of 3 Reveal next step →

## 4. Misconceptions and causal teaching

Misconceptions To Fix watch out ✗ Wrong: The horizontal component always uses $\sin$ and the vertical always uses $\cos$. ✓ Right: It depends on which axis the angle is measured from. For an angle to the horizontal $x$-axis, $F_x = F\cos\theta$ (adjacent) and $F_y = F\sin\theta$ (opposite). ✗ Wrong: A component can be larger than the vector it came from. ✓ Right: Each component is never larger than the original magnitude, because $\sin\theta$ and $\cos\theta$ are at most $1$. 

Explain the definition or physical cause before relying on the formula. A direction convention belongs on the task, not only in the answer. A graph is a relation between labelled quantities, not a picture of the road.

A 20.0 N force acts 60.0 degrees above +x. Find components.
