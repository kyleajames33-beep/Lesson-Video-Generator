## 3. Number and science check

Figures the page states (to be independently checked in the design; current statistics must come from a dated report):
- Below about 85 per cent of maximum, oxygen delivery can keep up and the work is predominantly aerobic.
- A session of maximal 30 metre sprints with three minutes between them is anaerobic training: each effort is supplied by phosphocreatine, and the long rest allows almost complete restoration, so every repetition is near-maximal.

## 4. Exam traps and student mistakes (from the page)

- The identical drill, two different sessions. Same distance, same number of repetitions, same effort from the athlete. Change only the recovery and you have changed which system is stressed, which adaptation results, and which quality improves.
