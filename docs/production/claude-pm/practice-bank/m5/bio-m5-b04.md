# Draft for owner review: bio-m5-b04

## 1. Explain (3 marks)

**Question:** A student says that the two strands of a DNA molecule have identical base sequences. Explain why this is incorrect and how their relationship makes each strand useful during replication.

**Marking criteria:** 1 mark for complementary rather than identical sequences; 1 for A pairing with T and C with G; 1 for each strand acting as a template.

**Sample answer:** The strands are complementary, not identical: A pairs with T and C pairs with G. When they separate, each original strand can act as a template that determines the sequence of a new partner.

## 2. Apply (4 marks)

**Question:** A section of one DNA strand reads 5′-ATCGGA-3′. Write the complementary strand in its antiparallel direction and explain why the new sequence is predictable.

**Marking criteria:** 1 mark for 3′-TAGCCT-5′; 1 for antiparallel orientation; 1 for A–T; 1 for C–G pairing.

**Sample answer:** The complementary strand is 3′-TAGCCT-5′. It runs in the opposite direction. Each base specifies its partner: A pairs with T and C with G.

## 3. Analyse (5 marks)

**Question:** A DNA molecule has one strand labelled with a detectable isotope and one unlabelled strand. It replicates once using unlabelled nucleotides. Predict the composition of both daughter molecules and explain how the result supports semi-conservative replication.

**Marking criteria:** 1 mark for two daughter molecules; 1 for each containing one original strand; 1 for each containing one newly made strand; 1 for label in only one daughter molecule; 1 for explaining conservation of a template strand.

**Sample answer:** Two DNA molecules form. Each has one original template strand and one new unlabelled strand. One daughter contains the labelled original strand and the other contains the unlabelled original strand. Each daughter retains one parental strand, which is why replication is semi-conservative.
