## 1. Explain (3 marks)

**Question:** Explain why pure solids are omitted from a Kc expression and why moles must be divided by volume before substitution.

**Marking criteria:** 1 mark for constant pure solid activity; 1 for Kc using concentrations; 1 for c = n/V.

**Sample answer:** A pure solid has constant activity and is not written in Kc. Dissolved or gaseous amounts must be converted to mol L⁻¹ using c = n/V before substitution.

## 2. Calculate (4 marks)

**Question:** For A(g) ⇌ B(g), 0.30 mol of A and 0.60 mol of B are present at equilibrium in a 2.0 L vessel. Calculate Kc. The vessel also contains excess solid catalyst.

**Marking criteria:** 1 mark each for [A] = 0.15 and [B] = 0.30 mol L⁻¹; 1 for Kc expression; 1 for Kc = 2.0.

**Sample answer:** [A] = 0.30/2.0 = 0.15 and [B] = 0.60/2.0 = 0.30 mol L⁻¹. Kc = [B]/[A] = 0.30/0.15 = 2.0. The catalyst is excluded.

## 3. Analyse (5 marks)

**Question:** For CaCO₃(s) ⇌ CaO(s) + CO₂(g), Kc = 0.20 mol L⁻¹ at a stated temperature. A 5.0 L vessel initially contains 1.0 mol CaCO₃, 2.0 mol CaO and 2.0 mol CO₂. State the net direction, calculate the final CO₂ amount, and explain what happens to CaCO₃.

**Marking criteria:** 1 mark for Q = 0.40 mol L⁻¹; 1 for Q > K; 1 for reverse direction; 1 for final CO₂ = 1.0 mol; 1 for CaCO₃ increasing by 1.0 mol if sufficient CaO remains.

**Sample answer:** Q = [CO₂] = 2.0/5.0 = 0.40 mol L⁻¹, above K. The reverse reaction consumes CO₂. At equilibrium n(CO₂) = 0.20 × 5.0 = 1.0 mol, so 1.0 mol of CaCO₃ forms from 1.0 mol of the available CaO.
