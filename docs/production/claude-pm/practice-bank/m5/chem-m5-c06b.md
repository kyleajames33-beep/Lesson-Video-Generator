# Draft for owner review: chem-m5-c06b

## 1. Explain (3 marks)

**Question:** Explain why the change row for A(aq) ⇌ B(aq) can be written −x for A and +x for B when a mixture starts with A only.

**Marking criteria:** 1 mark for forward conversion; 1 for 1:1 stoichiometry; 1 for opposite signs.

**Sample answer:** A is consumed to make B. The equation uses one A to make one B, so if A falls by x mol L⁻¹, B rises by x mol L⁻¹.

## 2. Calculate (4 marks)

**Question:** For A(aq) ⇌ B(aq), Kc = 3.0. Initially [A] = 0.80 mol L⁻¹ and [B] = 0. Calculate both equilibrium concentrations.

**Marking criteria:** 1 mark for K = x/(0.80 − x); 1 for x = 0.60; 1 for [A] = 0.20; 1 for [B] = 0.60 mol L⁻¹.

**Sample answer:** 3.0 = x/(0.80 − x), giving 2.40 − 3x = x and x = 0.60. Therefore [A]e = 0.20 and [B]e = 0.60 mol L⁻¹.

## 3. Calculate (5 marks)

**Question:** For 2A(g) ⇌ 2B(g), Kc = 9.0. A vessel initially contains [A] = 1.00 mol L⁻¹ and no B. Set up an ICE table and calculate both equilibrium concentrations without a quadratic formula.

**Marking criteria:** 1 mark for E row [A] = 1 − x and [B] = x; 1 for 9 = x²/(1 − x)²; 1 for taking the positive square root, 3 = x/(1 − x); 1 for x = 0.75; 1 for [A] = 0.25 and [B] = 0.75 mol L⁻¹.

**Sample answer:** E: [A] = 1 − x, [B] = x. Then 9 = x²/(1 − x)², so 3 = x/(1 − x). Solving gives x = 0.75. Thus [A]e = 0.25 and [B]e = 0.75 mol L⁻¹.
