## 1. Explain (3 marks)

**Question:** Explain how K changes when a balanced equilibrium equation is reversed at the same temperature.

**Marking criteria:** 1 mark for reversing numerator and denominator; 1 for reciprocal K; 1 for same temperature condition.

**Sample answer:** Reversing the equation swaps products and reactants in the expression, so the new K is 1/K for the original equation at the same temperature.

## 2. Calculate (4 marks)

**Question:** For A(g) ⇌ B(g), Kc = 0.25 at 300 K. A question instead writes B(g) ⇌ A(g). Calculate Kc for this reversed equation and the equilibrium ratio [A]/[B].

**Marking criteria:** 1 mark for reciprocal; 1 for reversed K = 4.0; 1 for [A]/[B] as reversed expression; 1 for ratio 4.0.

**Sample answer:** Reversed Kc = 1/0.25 = 4.0. For B ⇌ A, Kc = [A]/[B], so that ratio is 4.0 at equilibrium.

## 3. Analyse (5 marks)

**Question:** For 2X(g) ⇌ Y(g), Kc = 1.0 × 10⁻⁴ L mol⁻¹. Initially [X] = 1.00 mol L⁻¹ and [Y] = 0. Use a small-change approximation to estimate equilibrium concentrations. Check the percentage change in [X] and judge whether the approximation is reasonable.

**Marking criteria:** 1 mark for E row [X] = 1 − 2x and [Y] = x; 1 for x ≈ 1.0 × 10⁻⁴; 1 for [Y] ≈ 1.0 × 10⁻⁴; 1 for [X] ≈ 0.9998; 1 for 0.020% change and justified approximation.

**Sample answer:** Kc = x/(1 − 2x)². Taking 1 − 2x ≈ 1 gives x ≈ 1.0 × 10⁻⁴ mol L⁻¹. Thus [Y] ≈ 1.0 × 10⁻⁴ and [X] ≈ 0.9998 mol L⁻¹. The change in X is 0.0002/1.00 × 100 = 0.020%, so the shortcut is reasonable.
