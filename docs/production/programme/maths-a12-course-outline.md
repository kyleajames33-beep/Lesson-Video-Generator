# Year 12 Advanced: proposed whole-course outline

Brief 136 research, 1 November 2026. All 158 official Year 12 points have an owner, including the existing d01-d10. Assignment is a proposed teaching home, not approval or evidence that a site page fully teaches it. No unowned points. Exact source HTML and point-to-video ledger are in the companion JSON.

Recommended order: remaining differentiation/applications, trig graph modelling, integration and rate/motion applications, sequences then finance, random variables, optional mixed practice. This respects prerequisites and the owner's finance-after-calculus decision. NSW specifies the content, not this exact video timetable. Finance requires a cash-flow kit; continuous probability requires integral meaning.
