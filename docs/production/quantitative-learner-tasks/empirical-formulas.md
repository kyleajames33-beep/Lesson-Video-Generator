An analysed sample contains approximately 30.45% nitrogen and 69.55% oxygen by
mass. Its measured molar mass is approximately 92.02 g mol⁻¹. Use N = 14.01 and
O = 16.00 g mol⁻¹. Treat these rounded data as consistent with a small whole-number
ratio; retain guard digits during calculation.

1. Choose and state a calculation basis. Convert each element mass to moles.
2. Use unrounded mole amounts to infer the empirical formula. Show the ratio
   before selecting integers.
3. Infer the molecular formula using the unrounded empirical-formula mass.
4. A student says, “The molecular formula proves the sample is a particular pure
   compound.” Explain what the data do and do not establish, assuming a single
   molecular substance for the formula calculation.
5. In a second hypothetical composition calculation, the mole ratio is
   N : O = 1.00 : 1.50. What simplest whole-number formula is supported? Explain
   why independently rounding the second ratio to 2 is unsuitable.
