# Quantitative learner tasks

Six source-only formative drafts accompany the revised Chemistry lesson proposals.
They use unseen numbers and require explanations as well as calculation. They are
original practice tasks, not official NESA questions or an approved formal assessment.
Data labelled synthetic were constructed for reasoning practice. They are not
measurements collected by a learner.

| Student sheet | Primary evidence sought |
| --- | --- |
| [Empirical and molecular formulas](empirical-formulas.md) | Mole ratio, multiplier, precision and limits on identity |
| [Gravimetry](gravimetry.md) | Known weighing form, concentration and conflicting method errors |
| [Combustion](combustion.md) | Captured heat, per-mole estimate and reference comparison |
| [Neutralisation](neutralisation.md) | Limiting reagent, water stoichiometry and heat-model assumptions |
| [Dissolution](dissolution.md) | Signed heat balance, solution mass and matched reference conditions |
| [Back and conductometric titration](titration.md) | Aliquot scaling, residual acid and data-derived endpoint |

Keep the [teacher key](teacher-key.md) separate from student sheets. Each sheet
provides an entry check and response space. Let students complete the main task
before releasing feedback. The proposed 15 to 25 minute working time is a planning
estimate; observe actual completion and accessibility needs before setting a limit.

Record the task version, student response, method decisions, reasoning gaps and
support given. A score is evidence for these tasks only, not a validated mastery
threshold. Recheck a missed decision with an altered prompt after feedback.

The gravimetry sheet is a Year 11 quantitative extension. Gravimetric analysis is
explicitly listed in the 2017 Year 12 Module 8, where investigations and/or data
processing are allowed. Neutralisation calorimetry is a Module 4 application;
the specifically named neutralisation practical also appears in Year 12 Module 6.
See the [curriculum audit](../quantitative-curriculum-and-delivery-2026-10-03.md).

Each practical follow-up is a planning brief. A teacher still needs to select the
school procedure, apparatus, quantities, controls, risk assessment, waste route
and local supervision before any experiment. Written tasks and videos do not
establish that a student conducted a practical investigation. Track actual
practical and depth-study time separately at course level.

Teacher science/curriculum review, pilot responses and formal assessment
suitability remain pending. These files require no rendering or audio generation.
